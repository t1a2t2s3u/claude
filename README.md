# まいつき帳

毎月の固定費・サブスクをひと目で確認できる、1ファイル完結の家計ページです。

## できること

- 支払いの登録・編集・削除（名前 / 金額 / 頻度 / 支払日 / カテゴリ / 支払い方法 / メモ）
- 頻度は毎月・隔月・年1回に対応。月合計や年間ビューに正しく反映されます
- ヒーローカード：月合計・支払い済み・これから・月平均、カテゴリ別内訳バー、次の支払い
- 3つのビュー：支払日順の**リスト**（過ぎた日は「済」判子）、月間**カレンダー**、**年間**（月別チャート＋カテゴリ別年間集計）
- 月送りナビゲーション（過去・未来の月の内訳を確認）
- 検索・カテゴリ・支払い方法での絞り込み
- よくある支払いのプリセット入力、CSV書き出し（Artifact 上のみ）
- 29〜31日設定の支払いは、日数が足りない月は自動的に月末扱い

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや依存関係はありません。

データの保存先は開き方によって変わります。

- **Claude の Artifact として公開した場合**: 変更はページ自体に保存され、どの端末から開いても同じ内容になります（`artifact` capability による自己再公開）。
- **ローカルでファイルを直接開いた場合**: ブラウザの `localStorage` に保存されます（その端末のみ）。

## 実装メモ

- 単一の HTML ファイル。CSS / JS はすべてインライン、外部依存は Google Fonts のみ。
- アプリの状態は `<script type="application/json" id="app-state">` に JSON として埋め込まれ、保存時はスクリプト自身のソース（`document.currentScript.textContent`）から新しいドキュメントを組み立てて再公開します。
- カテゴリ配色は色覚多様性（CVD）検証済みのカテゴリカルパレットを使用。
- ライト / ダークテーマ両対応（`prefers-color-scheme` と `data-theme` 属性）。
