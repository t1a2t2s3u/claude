# 株式投資シミュレータ

架空の市場・架空の銘柄で株式売買を練習できる、ブラウザだけで動くシミュレータです。
外部 API もビルドツールも使いません（依存パッケージ 0、素の ES モジュール）。

![構成](https://img.shields.io/badge/dependencies-none-3ecf8e) ![tests](https://img.shields.io/badge/tests-node%3Atest-2f6bd8)

## 使い方

```bash
npm start        # → http://localhost:5173
npm test         # ロジックのユニットテスト
```

`index.html` は ES モジュールを読み込むため、`file://` で直接開かず必ず `npm start`
（`tools/serve.js` の静的サーバ）経由でアクセスしてください。

## できること

- **10 銘柄の架空マーケット** — セクター・β・ボラティリティ・配当利回りがそれぞれ異なる
- **成行注文** — その場で約定（スリッページ 0.05%）
- **指値注文** — 翌営業日以降、値幅が指値に届いた日に約定。未約定分は取消可能
- **手数料** — 約定代金の 0.1%（最低 ¥55 / 上限 ¥1,100）
- **配当** — 3 月・9 月の月末営業日に、年間利回りの半分を保有株数ぶん受け取る
- **時間の進行** — 1 日 / 5 日 / 20 日送り、自動再生（スペースキーで 1 日、`a` で自動再生の切替）
- **チャート** — ローソク足（陽線＝赤・陰線＝青）＋ 出来高 ＋ 5 日/25 日移動平均、資産推移の折れ線
- **ニュース** — 個別銘柄・セクター・市場全体のイベントが株価に反映される
- **成績** — 実現/評価損益、最大ドローダウン、年率ボラティリティ、シャープレシオ、勝率、
  プロフィットファクター
- **自動保存** — 状態は localStorage に保存され、リロードしても続きから再開できる

## 相場モデル

1 営業日ぶんのリターンを、次のように分解して積み上げています（`src/market.js`）。

```
r = 固有ドリフト/252
  + β × 市場要因            ← 全銘柄で共有。銘柄間の相関はここから生まれる
  + 0.35 × セクター要因     ← 同業種で共通
  + 固有ノイズ              ← 銘柄ごとの独立な変動
  + イベント                ← ニュースによるショック
```

終値は `前日終値 × exp(r)`。始値・高値・安値はその終値まわりのノイズから作り、
出来高は変動率が大きい日ほど膨らむようにしています。

乱数は `src/rng.js` の mulberry32 で、内部状態が 32bit 整数ひとつだけです。
状態をそのままセーブデータに載せられるので、**同じシードなら相場は完全に再現**されます。

## 構成

| パス | 役割 |
| --- | --- |
| `index.html` / `styles.css` | 画面の骨格とスタイル |
| `src/main.js` | エントリポイント（保存済み状態の復元 or 新規作成） |
| `src/ui.js` | DOM の組み立てとイベント配線 |
| `src/engine.js` | シミュレーション本体。日付進行・注文・配当・資産推移 |
| `src/market.js` | 価格生成とニュース抽選 |
| `src/instruments.js` | 架空銘柄マスタ |
| `src/portfolio.js` | 現金・ポジション・取得単価・実現損益 |
| `src/stats.js` | ドローダウンやシャープレシオなどの成績指標 |
| `src/chart.js` | Canvas 描画（ローソク足・折れ線） |
| `src/calendar.js` | 営業日カレンダー（土日と固定祝日を休場扱い） |
| `src/rng.js` / `src/format.js` / `src/storage.js` | 乱数・表示整形・localStorage |
| `test/` | `node:test` によるユニットテスト |
| `tools/serve.js` | 開発用の静的サーバ |

状態はすべて素の JSON オブジェクト（`engine.js` の `state`）に集約されており、
`JSON.stringify` で丸ごと保存 → 復元して続きを進められます。

## 割り切っていること

学習用のため、次は意図的に単純化しています。

- 空売り・信用取引・逆指値は未実装（現物の買い／売りのみ）
- 板や約定量の概念がなく、注文サイズは価格に影響しない
- 税金（譲渡益課税）は考慮していない
- 祝日は固定日のみ。振替休日やハッピーマンデーは再現していない
- 銘柄・株価・ニュースはすべて架空のもので、実在の企業や相場とは一切関係ありません
