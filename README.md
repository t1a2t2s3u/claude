# 星よみ手帳

**公開ページ: https://t1a2t2s3u.github.io/claude/**(デフォルトブランチへのマージで自動更新)

生年月日と血液型を入力すると、**今日の一枚(タロット)**、**恋愛・仕事・金運のパーソナル運勢**、**星座 × 干支 × 血液型の複合鑑定**、**四柱推命(簡易命式)**、**数秘術診断**、そして**ふたりの相性診断**まで楽しめる占いWebアプリです。ビルド不要・依存ライブラリなしの静的サイトとして動作します。

## 機能

### きょうの占いタブ

- **今日の一枚(タロット)** — ウェイト版フルデッキ**78枚**(大アルカナ22+小アルカナ56)から日替わりで1枚。伏せた5枚から直感で選ぶ演出つきで、正位置/逆位置、キーワード、メッセージ、恋愛・仕事・金運別のアドバイス(大アルカナは正逆で書き分け)を表示
- **過去・現在・未来の3枚引き** — 今日の一枚とは別に、重複しない3枚のスプレッドを展開
- **今日のあなたの運勢** — 恋愛運・仕事運・金運(各5段階+カテゴリ別アドバイス文)と総合運、ラッキーカラー、ラッキーアイテム、メッセージ
  - タロットも運勢も「日付 + 星座 + 干支 + 血液型」から決定的に生成。同じ日に同じ人が引けば必ず同じ結果になり、日付が変わると結果も変わります
- **複合プロフィール鑑定** — 12星座×干支×血液型の「あなたのタイプ」診断。星座の四元素×血液型の相乗効果コメント(16パターン)つき
- **四柱推命(簡易命式)** — 年柱・日柱の干支を算出し、日干(生まれ日の十干)からあなたの本質を10タイプで鑑定。日柱はユリウス通日による暦のうえで正確な計算です
- **数秘術診断** — 運命数(1〜9、マスターナンバー 11・22・33)と資質の解説
- **12星座デイリーランキング** — 星座単体の運勢による順位(自分の星座をハイライト)

- **月替わりの「季節のひとこと」** — 月が変わると自動で語り口が変わる季節メッセージつき
- **結果のシェア** — 今日の運勢・相性診断をSNS向けテキストでシェア(Web Share API/クリップボード)

### 相性診断タブ

- **ふたりの相性診断** — 2人分の生年月日と血液型から、星座(アスペクト)・血液型・干支(合冲刑害)・命式(干合/相生相剋/日支)の4軸で採点し、総合スコアと軸ごとの解説を表示。相性は日付に依存せず、同じふたりなら常に同じ結果です

### アプリとして

- 入力した生年月日・血液型は端末に記憶され、次回から入力不要
- PWA対応(manifest + アイコン)でホーム画面に追加可能

## メッセージの増やし方(飽きさせない仕組み)

日替わりメッセージはすべて `js/fortune.js` のプール(`MESSAGES` / `CATEGORY_ADVICE` / `SEASONAL_NOTES`)への**追記だけ**で増やせます。抽選ロジックの変更は不要で、`npm test` がプールの体裁(最低本数・空文字なし・全12ヶ月分)を自動検証します。毎月1日にはGitHub Actionsが「今月の鑑定メッセージを増やす」リマインダーIssueを自動作成します(`.github/workflows/monthly-content-reminder.yml`)。

## 動かし方

静的ファイルのみなので、任意のHTTPサーバーでルートを配信すれば動きます。

```sh
# 例: Python
python3 -m http.server 3000

# 例: Node (serve)
npm start
```

ブラウザで http://localhost:3000 を開いてください。
(`index.html` を `file://` で直接開くと、ブラウザによってはESモジュールの読み込みがブロックされます。)

## テスト

占いロジック(星座判定・数秘術・運勢生成)はNode標準のテストランナーでテストしています。

```sh
npm test
```

## 構成

```
index.html          エントリポイント(タブ構成の画面構造)
assets/tarot/       タロットカードの絵柄(ウェイト版、大アルカナ22枚)
css/style.css       スタイル(夜空テーマ、レスポンシブ対応)
js/zodiac.js        12星座データと星座判定
js/eto.js           干支(十二支)データと判定
js/bloodtype.js     血液型の性質データ
js/composite.js     星座×干支×血液型の複合プロフィール生成
js/numerology.js    数秘術(運命数)の計算と意味データ
js/fourpillars.js   四柱推命(年柱・日柱・日干)の計算と意味データ
js/tarot.js         タロット(大アルカナ22枚)データと今日の一枚の選択
js/compatibility.js ふたりの相性診断(4軸スコアリング)
js/fortune.js       日替わり運勢の決定的生成(シード付き乱数)
js/main.js          フォームと結果表示のDOM制御
test/               node --test によるロジックのユニットテスト
```

ロジック(`main.js` 以外の `js/` 各モジュール)はDOMに依存しないESモジュールとして分離してあり、ブラウザとNodeの両方から同じコードを利用しています。

## 画像クレジット

タロットカードの絵柄は、1909年に出版された**ウェイト版タロット(ライダー・ウェイト・スミス版、画: パメラ・コールマン・スミス)**のスキャン画像です。原画はパブリックドメインで、画像ファイルはMITライセンスの [krates98/tarotcardapi](https://github.com/krates98/tarotcardapi) から取得しています。

干支は一般的な慣習に合わせて元日切り替えの暦年で判定しています(旧暦・立春は考慮していません)。
