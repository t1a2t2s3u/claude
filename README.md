# Sonae（そなえ）

毎月の支払い・仕事の収支・税金の目安をひと目で確認できる、1ファイル完結の家計＆フリーランス収支ページです。

確定申告のたびに税金に慌てないよう、**毎月いくら取り分けておけばよいか**を主役に据えています。名前は「備え」から。

## 3つのセクション

### 支払い（固定費）
- 支払いの登録・編集・削除（名前 / 金額 / 頻度 / 支払日 / カテゴリ / 支払い方法 / メモ）
- 頻度は毎月・隔月・年1回に対応
- リスト（過ぎた日は「済」判子）・カレンダー・年間の3ビュー、月送りナビゲーション
- 検索・カテゴリ・支払い方法での絞り込み、プリセット入力、CSV書き出し
- 「経費にする割合（家事按分）」を設定すると、その分が仕事の経費として税金計算に反映

### 仕事の収支
- 収入・経費を**日付単位**で記録（科目・メモ付き）。日付ピッカーで入力し、仕訳CSVにもその日付で出力される
- 年間の収支サマリーと月別の収入・経費バーチャート。
  **左に「¥25万」のようなきりのいい目盛り**を引き、いちばん高い月にだけ金額を書き添えます
  （すべての棒に数字を並べると読めなくなるため）。ホバー／タップで各月の内訳も出ます
- 「月別」と「年間の一覧」の2ビュー。一覧では**その年の全記録を日付順**に並べ（新しい順／古い順を切替）、**収入だけ／経費だけ**に絞り込め、各行からそのまま編集・削除できる
- 取引先・内容の入力欄では、**前に入力した名前が候補**として出る（同じ種別のものを新しい順に）。候補から選ぶと科目も前回のものが入る
- **未入金の管理**：売上を「未入金」で登録して入金予定日を入れると、
  入金待ちの一覧と**期日超過**が出る。発生主義なので未入金でも税金の計算には入る（その旨も表示）
- **請求書**：インボイス（適格請求書）の記載事項を満たす請求書を作成。
  保存すると**未入金の売上として自動で記録**され、入金管理と税金計算につながる。
  印刷用HTMLに書き出して、ブラウザの印刷からPDF保存・紙に出力できる
- 固定費の按分額を経費として自動合算、収支CSV書き出し
- **仕訳CSVの書き出し**：振替伝票形式（取引日／借方・貸方の勘定科目・金額・税区分／摘要）で、会計ソフトの仕訳インポートに取り込める。収入は「事業主貸／売上高」、経費は「各科目／事業主借」、家事按分は月ごとに科目単位でまとめて出力

### 税金の目安
- 働き方（個人事業主・フリーランス／会社員＋副業）を設定で切り替え
- 個人事業主：所得税（復興特別所得税込み）・住民税・個人事業税・消費税・国民年金・国民健康保険を概算し、手取りと「毎月の積立目安」を表示
- **消費税は3方式に対応**：2割特例／簡易課税（第1〜6種のみなし仕入率）／本則課税（課税仕入れの割合を指定可能。居住用家賃・保険・ローンは課税仕入れから自動除外）
- 国民健康保険は**都道府県→市区町村を選択して算定**：
  - 実料率を収録：東京23区の各区・横浜市・大阪市・福岡市（令和8年度の公式料率、子ども・子育て支援金分込み）
  - それ以外の市区町村：**33都道府県分の「都道府県標準保険料率」**（各都道府県の公式公表資料・令和7/8年度）で概算
  - 未収録の県・正確に計算したい場合：どの都道府県でも「料率を自分で入力」を選び、医療分・支援分・介護分の所得割／均等割／平等割を直接入力できる（未入力のまま保存すると警告が出る）
  - 世帯の加入人数も設定できる
- **国保組合・任意継続などの人向け**：健康保険の種類で「金額を入力」を選ぶと、月額保険料をそのまま入力でき、社会保険料控除にも反映される
  （このとき国保の欄は消えず、薄く表示されたまま残るので設定を見失わない）
- 収入が未登録でも、国民年金・健康保険など収入に関係なくかかる分の目安と内訳を表示
- 会社員＋副業：副業による追加の所得税・住民税、確定申告の要否（20万円判定）を表示
- 青色申告（65万/10万控除）・白色申告、40〜64歳の国保介護分に対応

### 所得控除
項目ごとに入力すると、**所得税と住民税それぞれの控除額**で計算します
（生命保険料・地震保険料・人的控除は住民税のほうが小さいため）。

- **掛金が全額引けるもの**：小規模企業共済（上限84万）・iDeCo（上限81.6万）・
  国民年金基金／付加年金。国民年金基金と付加年金は公的年金への上乗せなので、
  社会保険料控除として扱い「税金・社会保険の目安」の合計にも入れる。
  小規模企業共済とiDeCoは自分の資産なので合計には入れず、控除にだけ効かせる
- **生命保険料控除**：一般・介護医療・個人年金の支払保険料から新制度の式で計算
  （所得税は各4万・合計12万、住民税は各2.8万・合計7万が上限）
- **地震保険料控除**：所得税は全額（上限5万）、住民税は半額（上限2.5万）
- **医療費控除**：10万円（総所得200万未満なら所得の5%）を超えた分
- **配偶者控除・配偶者特別控除**：本人の所得で3段階に減る仕組みと、
  配偶者の所得58万〜133万の逓減表に対応
- **扶養控除**：一般／特定（19〜22歳）／老人（同居・別居）を人数で
- **障害者控除**（一般・特別・同居特別）・**ひとり親**・**寡婦**・**勤労学生**
- **住民税の調整控除**を、人的控除の差の合計から正しく計算
  （扶養家族がいるほど差が大きくなるため、定額では合わない）
- **ふるさと納税**：所得税は寄附金控除、住民税は基本分＋特例分の税額控除として計算。
  **実質2,000円で収まる上限の目安**を表示し、超えていれば警告する

### 年をまたぐ計算
- **純損失の繰越控除**：青色申告なら赤字を3年間繰り越し、黒字の年から差し引く。
  途中の黒字で消費される分と4年目の期限切れも順に処理し、個人事業税にも同じように適用
- **予定納税**：前年の所得税が15万円以上なら、7月・11月に3分の1ずつ前払いした前提で計算。
  確定申告では差額だけを納め、前払いが多ければ還付見込みとして表示
- **前年比**：収支の画面に、前年からの収入・経費・利益の増減を金額と％で表示

### 納付と積立
- **納付スケジュール**：所得税（3/15）・消費税（3/31）・住民税（4期）・個人事業税（2期）を、
  金額と期日つきで一覧。期日が近いもの・過ぎたものを色で示し、1件ずつ**納付済みにチェック**できる
- **毎月かかるもの**：国民年金と国民健康保険の月額
- **納税用の積立**：目標（その年の税金＋社会保険の合計）に対して、いま
  いくら貯まっているか。残りと「確定申告まで毎月いくら積めばいいか」を表示。
  引き出しはマイナスで記録

### 節税のヒント
記録した金額から**その人に当てはまるものだけ**を選んで、税金の目安の下に表示します。
- **限界税率で効果を見積もる**：いまの所得で「経費を1万円増やしたら」「所得控除を1万円増やしたら」
  いくら軽くなるかを計算し、各ヒントの年間の効果額も同じ税率で見積もる
- 経費と所得控除を区別：経費は所得税・住民税・個人事業税・**国保**に効くが、
  小規模企業共済やiDeCoのような所得控除は所得税・住民税にしか効かない、という差を明示する
- 課税所得が0の年は、控除型の節税に「いまは効果がない」と注記し、
  代わりに国民年金の免除・国保の軽減など**負担そのものを減らす**話を上位に出す
- 収録している内容：青色申告65万円控除／家事按分／30万円未満の少額減価償却資産／
  小規模企業共済／iDeCo／付加年金／国民年金の前納割引・免除／国保の均等割軽減／
  消費税3方式の有利判定と2割特例の終了／個人事業税／青色事業専従者給与／赤字の繰越／ふるさと納税
- 届出書の名前と期限（青色申告承認申請書は3月15日、簡易課税選択届出書は前年12月31日 など）を添える
- 効果額の大きい順に4件を表示し、残りは「ほかのヒントも見る」で開く

### 税額計算の前提（概算）
- 所得税の基礎控除は令和7・8年分（暫定上乗せ特例込み）、給与所得控除は改正後（最低65万円）
- 国民年金は令和8年度（月額17,920円）
- 国民健康保険は選択した市区町村の実料率または都道府県標準保険料率（未収録の県は入力した料率／国保組合等は入力額）
- あくまで概算であり、実際の税額は確定申告・自治体の通知で確定します

### 決算書の数字
確定申告のときに**そのまま書き写せる**科目別の合計を出します。

- 記録した経費を申告書の科目名（外注工賃・地代家賃・接待交際費…）に置きかえて集計
- **家事按分も同じ科目に合流**させ、「うち家事按分 ○円」と内訳を添える
- 収入計／売上原価／経費計／差引金額／青色申告特別控除／所得金額まで
- CSVでも書き出せる
- 集計に含まれないもの（減価償却費・棚卸・専従者給与）を明記する

## 「支払い」と「経費」の使い分け

ここで迷う人が多いので、アプリの中に説明を置いています。

- **支払い**は「いつ・いくら口座から出ていくか」を見るところ。
  経費にする割合を0%にして登録してもよく、カレンダーに支払日が並ぶこと自体に意味がある
- **仕事の収支の経費**は、確定申告に出す経費を科目つきで積み上げるところ
- 判断は「私生活でも使うか → 毎月決まった額か → 都度か」の順

フッターの**「支払いと経費の使い分け」**に、判断の流れ・具体例の表・
注意点（二重計上、生命保険や年金は経費でなく所得控除、
支払い側は決算書の科目が5つに限られること、年払いの計上月）をまとめてあります。
同じ内容の短いヒントを、支払いの「経費にする割合」欄と経費の入力画面にも出します。

## はじめて開いたとき

記録がひとつもない状態では、**働き方・都道府県・申告のしかた**の3つだけを聞く画面が出ます。
これが決まらないと税金の目安がその人の数字にならないためです。
「まだ決めていない」を選べば白色として計算し、青色にした場合の差額はあとでヒントに出ます。
「あとで」で飛ばすこともできます。

## テスト

```
node test/tax.test.mjs
```

`index.html` を `node:vm` の中で最小限のDOMもどきの上に起動し、
手計算で確かめた100件あまりの金額を照合します。ブラウザもパッケージも要りません。
税計算にかかわるところを直したら必ず実行してください。
落ちたら、**新しい数字を手で確かめてから**期待値を直します（逆はしない）。

## 税率・料率の基準年度

`TAX.basisYear` に、計算の元にしている年度を持たせています。
その年を過ぎると「税率・料率が○年度のままです」という警告を税金の画面に出します。
古い率のまま黙って計算し続けるのが、このアプリのいちばん危ない壊れ方だからです。
年度が変わったら `TAX`・`NHI_STD`・`NHI_PRESETS` と `basisYear` を更新してください。

## データとバックアップ

- 入力した内容は**この端末の中だけ**に保存されます（外部に送信しません）
- フッターの「データと設定」から：
  - **バックアップの書き出し**（JSON 1ファイル）と**復元**。
    復元前に置きかえ内容を件数で確認してから実行します
  - 最後のバックアップから90日たつと、フッターにそっと表示が出ます
  - **明細CSVの取り込み**：銀行やカードのCSVを読み込み、
    日付・摘要・金額の列を選ぶだけで収支に登録。列は自動で推測し、
    入金／出金が別列でも1列（±）でも、カード明細（すべて経費）でも扱えます。
    取り込み前に件数と内容を確認でき、同じ日付・金額の記録があるものは重複候補として知らせます
  - **請求書に載せる自分の情報**（屋号・住所・登録番号・振込先・締め日と入金条件）
- 「このアプリについて」に、データの扱い・計算結果の位置づけ（税務相談ではないこと）・
  計算の前提をまとめてあります

## アプリとして配布する

`release/` に PWA 用のファイル（manifest・Service Worker・アイコン）が入っています。
`index.html` と同じ階層に置いて HTTPS で配信すると、ホーム画面から全画面で起動し、
オフラインでも開けるようになります。詳しくは `release/README.md` を参照してください。

Claude の Artifact 上ではこれらを読み込まないので、これまでどおり動きます。

## 方針

業種を選ばないアプリにしています。画面の文言も、特定の職種を前提にした
言い回し（現場・工事など）は避け、どの個人事業主が読んでも当てはまる言葉にしています。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや依存関係はありません。

- **Claude の Artifact として公開した場合**: 変更はページ自体に保存され、どの端末から開いても同じ内容になります（`artifact` capability による自己再公開）。
- **ローカルでファイルを直接開いた場合**: ブラウザの `localStorage` に保存されます（その端末のみ）。

## 実装メモ

- 単一の HTML ファイル。CSS / JS はすべてインライン、外部依存は Google Fonts のみ。
- アプリの状態（v3: payments / biz / profile）は `<script type="application/json" id="app-state">` に JSON として埋め込まれ、保存時はスクリプト自身のソース（`document.currentScript.textContent`）から新しいドキュメントを組み立てて再公開します。旧バージョンのデータは自動移行されます。
- 税制パラメータはスクリプト冒頭の `TAX` 定数にまとまっています（年度更新はここを編集）。
- カテゴリ・チャート配色は色覚多様性（CVD）検証済みのカテゴリカルパレットを使用。
- ライト / ダークテーマ両対応（`prefers-color-scheme` と `data-theme` 属性）。
