# 星よみ手帳

生年月日を入力するだけで、**12星座の今日の運勢**と**数秘術(運命数)による性格診断**を表示する占いWebアプリです。ビルド不要・依存ライブラリなしの静的サイトとして動作します。

## 機能

- **星座判定** — 生年月日から12星座を判定し、星座の性質を表示
- **今日の運勢** — 総合運・恋愛運・仕事運・金運(各5段階)、ラッキーカラー、ラッキーアイテム、メッセージ
  - 「日付 + 星座」から決定的に生成するため、同じ日は誰が引いても同じ結果になり、日付が変わると結果も変わります
- **数秘術診断** — 生年月日から運命数(1〜9、マスターナンバー 11・22・33)を計算し、資質を解説
- **12星座デイリーランキング** — その日の全星座の順位を表示(自分の星座をハイライト)

## 動かし方

静的ファイルのみなので、任意のHTTPサーバーでルートを配信すれば動きます。

```sh
# 例: Python
python3 -m http.server 3000

# 例: Node (serve)
npm start
```

ブラウザで http://localhost:3000 を開いてください。
(`index.html` を `file://` で直接開くと、ブラウザによってはESモジュールの読み込みがブロックされます。)

## テスト

占いロジック(星座判定・数秘術・運勢生成)はNode標準のテストランナーでテストしています。

```sh
npm test
```

## 構成

```
index.html        エントリポイント(画面構造)
css/style.css     スタイル(夜空テーマ、レスポンシブ対応)
js/zodiac.js      12星座データと星座判定
js/numerology.js  数秘術(運命数)の計算と意味データ
js/fortune.js     日替わり運勢の決定的生成(シード付き乱数)
js/main.js        フォームと結果表示のDOM制御
test/             node --test によるロジックのユニットテスト
```

ロジック(`zodiac.js` / `numerology.js` / `fortune.js`)はDOMに依存しないESモジュールとして分離してあり、ブラウザとNodeの両方から同じコードを利用しています。
