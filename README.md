# 株式投資シミュレータ

ブラウザだけで動く株式投資シミュレータです。相場は 2 通りから選べます。

- **架空市場** — 乱数で生成した架空の 10 銘柄。データ取得なしですぐ遊べる
- **実データ** — 実在銘柄の日足を取り込み、その値動きを 1 日ずつ再生する

依存パッケージ 0・ビルドなしの素の ES モジュールで書かれています。

## 使い方

```bash
npm start         # → http://localhost:5173
npm test          # ロジックのユニットテスト
npm run import    # 実データの取り込み（S&P 500・505 銘柄・5 年ぶん）
npm run fetch     # 実データの取り込み（Yahoo/Stooq から最新の日足を取得）
```

`index.html` は ES モジュールを読み込むため、`file://` で直接開かず必ず `npm start`
（`tools/serve.js` の静的サーバ）経由でアクセスしてください。

## できること

- **2 つのモード** — 画面右上で「架空市場」と「実データ」を切り替えられる
- **10 銘柄の架空マーケット** — セクター・β・ボラティリティ・配当利回りがそれぞれ異なる
- **成行注文** — その場で約定（スリッページ 0.05%）
- **指値注文** — 翌営業日以降、値幅が指値に届いた日に約定。未約定分は取消可能
- **手数料** — 約定代金の 0.1%（最低 ¥55 / 上限 ¥1,100）
- **配当** — 3 月・9 月の月末営業日に、年間利回りの半分を保有株数ぶん受け取る
- **時間の進行** — 1 日 / 5 日 / 20 日送り、自動再生（スペースキーで 1 日、`a` で自動再生の切替）
- **チャート** — ローソク足（陽線＝赤・陰線＝青）＋ 出来高 ＋ 5 日/25 日移動平均、資産推移の折れ線
- **ニュース** — 個別銘柄・セクター・市場全体のイベントが株価に反映される
- **成績** — 実現/評価損益、最大ドローダウン、年率ボラティリティ、シャープレシオ、勝率、
  プロフィットファクター
- **自動保存** — 状態は localStorage に保存され、リロードしても続きから再開できる

## 実データを取り込む

実データの入手方法は 2 つあり、どちらも `data/` に同じ形式で書き出します。
取り込みが済むと画面右上の「実データ」が使えるようになり、実際の値動きを
1 日ずつ再生しながら売買できます。

### 方法 1: S&P 500 データセット（`npm run import`・おすすめ）

GitHub 上で公開されている実データ（Kaggle "S&P 500 stock data", CC0）を取り込みます。
**S&P 500 全 505 銘柄・2013-02-08 〜 2018-02-07 の実際の日足**（約 30MB）で、
GitHub に届くネットワークなら企業プロキシ配下などでも取得できます。

```bash
npm run import               # 505 銘柄すべて
npm run import -- --limit 50 # 動作確認用に先頭 50 銘柄だけ
```

- ドル建てのまま取り込まれ、画面表示・手数料・初期資金（$30,000）もドルになる
- 銘柄名とセクターは現在の構成銘柄一覧から引くため、当時と入れ替わった銘柄は
  コード表示になる
- このデータセットに配当イベントは含まれない

### 方法 2: Yahoo / Stooq から取得（`npm run fetch`）

最新の日足が欲しいとき、日本株が欲しいときはこちら。株価配信元に直接アクセス
できるネットワークが必要です。

```bash
npm run fetch                                  # 日本の主要 40 銘柄・過去 10 年
npm run fetch -- --preset all --years 5        # 日米 60 銘柄・過去 5 年
npm run fetch -- --preset us                   # 米国主要 20 銘柄
npm run fetch -- --symbols 7203,6758,AAPL      # 銘柄を指定（4 桁数字は日本株）
npm run fetch -- --source stooq                # 取得元を Stooq に切り替え
```

| オプション | 既定 | 説明 |
| --- | --- | --- |
| `--preset` | `jp` | `jp`（日本 40 銘柄）/ `us`（米国 20 銘柄）/ `all` |
| `--symbols` | — | カンマ区切りの銘柄コード。プリセットより優先 |
| `--years` | `10` | 何年ぶんさかのぼるか |
| `--source` | `yahoo` | `yahoo` / `stooq`。失敗した銘柄はもう一方に自動フォールバック |
| `--base` | `JPY` | 基準通貨 |
| `--out` | `data` | 出力先ディレクトリ |
| `--limit` | `0` | 先頭 N 銘柄だけ取得（動作確認用） |

取得元は [Yahoo Finance](https://finance.yahoo.com/)（配当イベント付き）と
[Stooq](https://stooq.com/) です。どちらも公開されている日足で、リアルタイム気配では
ありません（当日終値の反映は取引終了後）。**個人の学習用途を前提としており、
取得したデータはリポジトリに含めていません**（`data/` は Git 管理外）。最新の株価に
更新したいときは `npm run fetch` を再実行してください。取引の続きは日付で結び直されるため、
取り込み直しても続きから遊べます。

### 実データモードの挙動

- **配当** — 実際の権利落ち日に、実際の 1 株あたり配当が入金される（`npm run fetch` のデータのみ）
- **単元** — 日本株は 100 株、米国株は 1 株から売買できる
- **通貨** — データセットの基準通貨で表示・計算する（S&P 500 はドル、`npm run fetch` は
  既定で外貨建てを取得時の為替レートで円換算）
- **開始時点** — 銘柄一覧の上で「1年前 / 3年前 / 5年前 / データの最初から」を選べる
- **終端** — 取り込んだ最終日まで進むとそこで止まる
- **値動き** — その日 ±3% 以上動いた銘柄が「値動き」タブに並ぶ（架空市場ではニュース）
- **絞り込み** — 銘柄一覧の検索欄で銘柄名・コードを部分一致で絞り込める

## 相場モデル（架空市場）

1 営業日ぶんのリターンを、次のように分解して積み上げています（`src/market.js`）。

```
r = 固有ドリフト/252
  + β × 市場要因            ← 全銘柄で共有。銘柄間の相関はここから生まれる
  + 0.35 × セクター要因     ← 同業種で共通
  + 固有ノイズ              ← 銘柄ごとの独立な変動
  + イベント                ← ニュースによるショック
```

終値は `前日終値 × exp(r)`。始値・高値・安値はその終値まわりのノイズから作り、
出来高は変動率が大きい日ほど膨らむようにしています。

乱数は `src/rng.js` の mulberry32 で、内部状態が 32bit 整数ひとつだけです。
状態をそのままセーブデータに載せられるので、**同じシードなら相場は完全に再現**されます。

## 構成

| パス | 役割 |
| --- | --- |
| `index.html` / `styles.css` | 画面の骨格とスタイル |
| `src/main.js` | エントリポイント（保存済み状態の復元 or 新規作成） |
| `src/dataset.js` | `data/` に取り込んだ実データの読み込み |
| `src/ui.js` | DOM の組み立てとイベント配線 |
| `src/engine.js` | シミュレーション本体。日付進行・注文・配当・資産推移 |
| `src/market.js` | 価格生成とニュース抽選 |
| `src/instruments.js` | 架空銘柄マスタ |
| `src/portfolio.js` | 現金・ポジション・取得単価・実現損益 |
| `src/stats.js` | ドローダウンやシャープレシオなどの成績指標 |
| `src/chart.js` | Canvas 描画（ローソク足・折れ線） |
| `src/calendar.js` | 営業日カレンダー（土日と固定祝日を休場扱い） |
| `src/rng.js` / `src/format.js` / `src/storage.js` | 乱数・表示整形・localStorage |
| `test/` | `node:test` によるユニットテスト |
| `tools/serve.js` | 開発用の静的サーバ |
| `tools/fetch-prices.js` | 実データ取得 CLI（`npm run fetch`） |
| `tools/import-sp500.js` | S&P 500 データセット取り込み CLI（`npm run import`） |
| `tools/tickers.js` | 取得対象の銘柄プリセット |
| `data/` | 取り込んだ株価（生成物。Git 管理外） |

状態はすべて素の JSON オブジェクト（`engine.js` の `state`）に集約されており、
`JSON.stringify` で丸ごと保存 → 復元して続きを進められます。

## 割り切っていること

学習用のため、次は意図的に単純化しています。

- 空売り・信用取引・逆指値は未実装（現物の買い／売りのみ）
- 板や約定量の概念がなく、注文サイズは価格に影響しない
- 税金（譲渡益課税）は考慮していない
- 実データモードでも、約定は日足の四本値に対する近似（ザラ場の値動きは見ていない）
- 株式分割は取得元の調整済み株価に依存する。分割日をまたぐ保有株数は調整されない
- 日米を混ぜると休場日がずれる。その日の足がない銘柄は前日の値のまま据え置く
- 架空市場モードの祝日は固定日のみ。振替休日やハッピーマンデーは再現していない
- 架空市場の銘柄・株価・ニュースはすべて創作で、実在の企業や相場とは関係ありません
- S&P 500 データセットは 2018 年まで。それ以降や日本株が欲しい場合は `npm run fetch` を使う
- 実データモードは過去の値動きの再生であり、将来の成績を示すものではありません
