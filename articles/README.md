# articles/

記事の置き場。ファイル名は `YYYY-MM-DD-スラッグ.md`。

流れ: **drafts → ready → published**

- `drafts/` — ライターが納品した下書き。校閲がここから拾う
- `ready/` — 校閲合格・投稿待ち。オーナーは末尾の「校閲メモ」の残作業
  （プレースホルダ埋め・【要確認】の確認）を済ませて note に投稿する
- `published/` — note に投稿し終えた記事。投稿したら ready/ からここへ
  移動し、note のURLをファイル先頭に追記する（SNS担当の告知トリガー、
  アナリストの計測対象になる）
