# タイトル案
1. （本命）うちの有料記事のネタが、出す前に無料で出回った — それでも「有料で出す部分」とは何か
2. 「AI系の有料note、買う価値ある？」に、先を越された側から答える
3. 手順はいずれ無料になる — それでもお金を払う価値が残る記事の、うちの見分け方

# 本文

身も蓋もない報告から始めます。**うちが準備してきた有料記事の核が、投稿する前に、ほかの書き手の無料記事として出回りました。**

うちには準備中の有料記事が3本あります。「AI秘書を作る完全手順書」「AI社員の『雇用契約書』（指示書ファイル）の書き方」「AI社員に何をどこまで任せるか」。このうち2本の核——**毎朝レポートが届く秘書を Claude Code で作る手順**と、**任せる前に承認を段階で考える枠組み**——と同じテーマの無料記事が、うちの投稿より先に note に出ました（チームの調査記録・2026-11-08より。見出しと冒頭から同じテーマだと判断したもので、有料部分があれば中身までは見ていません。だからその記事への評価はここでは書きません——むしろ、良い記事が無料で読める時代になった、というのが前提です）。

これは「売る側」なら誰でも直面する話です。今回は、先を越された当事者として、その顛末と、**それでも「有料で出す部分」とは何か**という結論を公開します。

【あなたの体験をここに: 「先に出された」と知ったときの率直な気持ち（1〜2文。悔しさでも、意外と冷静だったでも、実際のところを。なければこの一文は削除してください）】

## 正直な整理 — 「手順」と「枠組み」は、必ず無料化される

落ち着いて振り返ると、これは不運ではなく法則でした。この連載で扱ってきた話だけでも:

- うちが手作りした「見張り役AI」（成果物の点検係）と同じ発想は、のちに**公式の点検機能**になりました
- うちの秘書と同じ「毎朝ブリーフィングが届く」仕組みは、公式製品 **Claude Duet** として発表されました
- うちが指示書に書いてきた「どこまで任せるか」の線引きは、**自動モードの既定化**という形で製品の標準設定になりつつあります

手順と考え方の枠組みは、時間が経てば**必ず誰かが無料で書き、最後は公式機能になる**。うちの有料記事も、この法則の外にはいられなかった、というだけの話です。

## では、有料に何が残るのか — うちの答え

それでも有料で出す意味があるとすれば、無料化・公式化の法則が**届かないもの**だけです。うちの答えは3つです。

1. **現に動いている実物** — 13人分の指示書ファイルの全文。考え方の解説は複製できても、2ヶ月半動き続けている現物のファイル一式は、うちにしかありません
2. **実際に起きた事故と、直した記録** — 10日間誰も気づかなかった納品停止、監査役自身の誤りと訂正。失敗の記録は、体験した者にしか書けません
3. **工程そのもの** — 書く係だけでなく、監査役・仕上げ係まで含めて回る流れの実物。部品の作り方は無料で学べても、工程一式は現場からしか出てきません

ひとことで言えば、**「知識」は無料化するが、「記録と実物」は複製できない**。これがうちの線引きです。

## 買う側へ — AI系有料記事の、うちの見分け方

この整理は、そのまま「買う側」の基準にもなります。むしろ本題はこちらです。

- **手順やノウハウの解説が核の記事なら、まず無料を探してください。** 上の法則のとおり、手順はたいてい無料で見つかり、やがて公式ドキュメントになります。うちの有料記事の無料部分にも、考え方は出し惜しみせず書きます
- **お金を払う価値があるのは、「その人にしか書けない実物・実録」が入っている記事です。** 動いているファイルの現物、失敗した日付と原因の記録、直すまでの経緯。書き手の立場でしか手に入らないものが入っているかを、無料部分で確かめてから買う——うちが買う側に回るときの基準も、これです

「何が書いてあるか」ではなく「**それはその人からしか手に入らないか**」で見る、と言い換えてもいいと思います。

## 売る側としての結論

うちの有料3本は、この基準で**無料部分を書き直してから**出します。考え方の枠組みは無料部分で惜しまず説明し、有料部分の購入理由は「実物のファイル全文・事故と修正の記録・工程の実物」に寄せる、という方針がチームで決まり、書き直しの指示がすでに出ています。価格は据え置きの想定です（最終判断は、AIではなく人間のオーナーである私がします）。

先を越されたことを隠して出すこともできました。でもこの連載は、AIが書いていることも、失敗の記録も、隠さないことを武器にしてきました（その話は【AI開示記事のURL】に書いています）。ネタがかぶった事実より、かぶってもなお残る価値を言葉にできるかのほうが、売る側の仕事だと思っています。
