**他社さんのお見積りをお持ちなら、そのまま見せてください。** 無料で内容を確認し、
どこを見れば比べられるのかをお伝えします。

**当社に乗り換えていただくためのものではありません。** 診断した結果、
他社さんのお見積りのほうが良ければ、そのとおりお伝えします。

## なぜ無料でやるのか

外壁塗装のお見積りは、**お客様が比べられるようには書かれていないことが多い**からです。

「外壁塗装工事 一式 1,200,000円」とだけ書かれていたら、それが高いのか安いのか、
判断のしようがありません。何平米を、どの塗料で、何回塗るのかが分からないからです。

当社は**完全自社施工**で、お見積りをした人間が実際に塗ります。中間マージンが
乗らないので、**相見積りを歓迎できます**{.marker}。他社さんの見積りを見せていただいても、
こちらが困ることはありません。

## 見積書で、まず見る7か所

| 見るところ | なぜ見るのか |
|---|---|
| **「一式」ばかりになっていないか** | 数量と単価が書かれていないと、何と比べることもできません |
| **塗る面積（㎡）が書いてあるか** | 延床30坪の家なら、外壁はおおむね120〜150㎡が目安です |
| **塗料のメーカー名と製品名** | 「シリコン塗料」とだけ書かれていても、価格は倍近く違います |
| **何回塗ると書いてあるか** | 下塗り・中塗り・上塗りの3回塗りが基本です |
| **足場代が含まれているか** | 別途になっていると、後から15〜25万円ほど増えます |
| **コーキングと付帯部が入っているか** | 外壁だけの金額で、雨樋・破風・目地が別になっていることがあります |
| **保証の年数と、保証書が出るか** | 「保証します」と口で言うだけで、書面が出ない会社もあります |

**この7つが書かれている見積書は、それだけで信用できます。** 書いた会社が、
後から追加請求するつもりがないということだからです。

## こんな言われ方をしたときは、いったん持ち帰ってください

- **「今日契約していただければ、○○万円お引きします」**
- **最初の金額から、大幅に値引きされた**
- **「このままだと家が傷んで、大変なことになります」**
- **「近所で工事をしているので、足場代が浮きます」**

どれも**その場で決めさせるための言い方**です。外壁塗装は、1日待って
消えてなくなる工事ではありません。**急かされたら、それ自体が判断材料**{.marker}です。

> 当社はお見積りをお出しした後、こちらから繰り返しご連絡することはありません。
> お断りいただいても費用はかかりませんし、その後の営業もいたしません。

## 診断でお伝えできないこと

**「この見積りは高い」「安い」という断定はしません。** 建物を見ていないからです。

同じ30坪でも、下地の傷み具合、ひび割れの数、前回の塗装の状態で、必要な工事は
変わります。**高いお見積りが、必要な補修を含んでいて正しいこともあります。**

お伝えするのは、**書かれている内容から読み取れること**と、**書かれていないために
判断できないこと**の2つです。そのうえで、何を質問すればよいかをお伝えします。

## 診断の流れ

1. **お見積りの写真を送っていただく** — フォームかLINEで。**金額以外は伏せていただいて構いません**
2. **内容を確認して、ご連絡します** — 上の7か所と、気になった点をお伝えします
3. **ご希望があれば、現地調査**（無料） — 当社のお見積りが必要なければ、お出ししません
