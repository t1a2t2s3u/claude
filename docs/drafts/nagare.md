外壁塗装は、多くの方にとって**一生に1〜2回**の工事です。何をどう進めるのか
分からないまま、見知らぬ業者を家に入れることになります。

**不安なのは当たり前です。** このページでは、最初のご連絡から工事が終わるまで、
**何が起きて、何をお願いするのか**を順に書いておきます。

## 全体の流れ

| | やること | 目安 |
|---|---|---|
| **1** | お問い合わせ | 5分 |
| **2** | 現地調査 | 【要記入：所要時間】 |
| **3** | お見積りのご説明 | 【要記入：調査から何日後か】 |
| **4** | ご契約・日程の決定 | — |
| **5** | 近隣へのご挨拶 | 着工の前 |
| **6** | 足場の設置 | 半日〜1日 |
| **7** | 高圧洗浄 | 1日 |
| **8** | 下地の補修・コーキング工事 | 2〜4日 |
| **9** | 塗装（下塗り・中塗り・上塗り） | 4〜6日 |
| **10** | 点検・足場の解体 | 1日 |
| **11** | お引き渡し | 30分 |

**6から11まででおよそ10日間**です。天候で前後します。

## 1. お問い合わせ

お電話、フォーム、LINEのどれでも構いません。**「まだ工事するか決めていない」
という段階で問題ありません。**

このときにお聞きするのは、**お住まいの地域、建物のおおよその築年数、気になって
いる症状**くらいです。分からなければ「分からない」で構いません。

> **お見積りをお出しした後、こちらから繰り返しご連絡することはありません。**
> お断りいただいても費用はかかりませんし、その後の営業もいたしません。

## 2. 現地調査

ご都合のよい日に伺って、建物の状態を見せていただきます。
所要時間は**【要記入：現地調査の所要時間】**です。

見るのは、外壁の傷み具合、ひび割れやコーキングの状態、屋根、付帯部、
そして**塗装で足りるのか、補修が先に必要なのか**です。

**立ち会いは【要記入：終始必要か、最初と最後だけでよいか】です。**
お家の中に入る必要は、基本的にありません。

## 3. お見積りのご説明

調査から**【要記入：見積りが出るまでの日数】**でお出しします。

お見積りには、**塗料のメーカー名と製品名、塗る面積、工程、足場代**まで
書きます。「外壁塗装一式」という書き方はしません。

**その場で決めていただく必要はありません。** 他社さんと比べていただいて
構いませんし、ご家族と相談する時間も取ってください。

## 4. ご契約・日程の決定

内容にご納得いただいてからの契約です。着工日を決めます。

秋田は**4月〜11月が工事のできる時期**です。とくに4〜5月は希望が集中するので、
ご希望の時期の**2〜3か月前**にご相談いただくと余裕を持って進められます。

## 5. 近隣へのご挨拶

足場を組む音、高圧洗浄の水、塗料のにおい。**工事はご近所にも影響します。**

【要記入：挨拶に誰が行くか（当社が行く／一緒に行く）、いつ行くか、
粗品を持っていくか】

## 6. 足場の設置（半日〜1日）

**この日がいちばん音が出ます。** 金属の部材を組み立てるので、
ガチャンガチャンという音が半日ほど続きます。

足場には**飛散防止のシート**を張ります。このシートがある間は、
**窓の外が暗くなり、景色が見えにくくなります。** 工事が終われば元どおりです。

## 7. 高圧洗浄（1日）

古い塗膜、汚れ、苔を水で落とします。**この日は窓を開けられません。**
水が入ります。

洗ったあとは**しっかり乾かす日数**を取ります。秋田は湿気が強いので、
ここを急ぐと塗料が密着しません。**乾燥待ちで作業のない日があるのは、
手を抜いているのではなく、必要な工程です。**

## 8. 下地の補修・コーキング工事（2〜4日）

ひび割れを埋め、傷んだコーキングを撤去して打ち直します。

**ここが仕上がりを決めます。** 塗ってしまえば外からは見えない部分なので、
手を抜こうと思えば抜ける工程です。当社は**お見積りに工程を書いて**、
やったことが分かるようにしています。

## 9. 塗装（下塗り・中塗り・上塗り／4〜6日）

**3回塗りが基本**です。下塗りは接着剤の役割、中塗りと上塗りで色と厚みをつけます。

この期間は**養生**といって、窓やドアをビニールで覆います。
**覆った窓は開けられません。** どの窓をいつ覆うかは、事前にお伝えします。

## 10. 点検・足場の解体（1日）

塗り残しがないか、全体を見て回ります。**足場があるうちでないと直せない**ので、
ここで必ず確認します。

ご希望があれば、**足場に上がって一緒に見ていただくこともできます。**
普段は見られない屋根や2階の状態を、ご自身の目で確認できます。

## 11. お引き渡し

仕上がりをご確認いただき、**保証書を紙でお渡しします。**

完工から1年後に、無料で点検に伺います。
→ [保証とアフター点検](/hosho/)

## 工事中の暮らしについて

| よくあるご心配 | お答え |
|---|---|
| **引っ越しは必要？** | **必要ありません。**お住まいのままで大丈夫です |
| **毎日家にいないとダメ？** | 【要記入：在宅が必要か。留守でも進められるか】 |
| **洗濯物は干せる？** | 【要記入：外に干せない期間】 |
| **窓は開けられる？** | 高圧洗浄の日と、養生をしている間は開けられません |
| **車はどうすれば？** | 【要記入：移動をお願いするか。足場や塗料の飛散を考えると？】 |
| **お茶出しは必要？** | 【要記入：不要と言い切ってよいか】 |
| **ペットがいます** | においと音がします。心配な場合は事前にご相談ください |

## お金のこと

**お見積りの金額から増えることは、基本的にありません。**

ただし、足場を組んで近くで見て初めて分かる傷みが出ることはあります。
その場合は**作業を止めて、写真を見ていただき、ご相談してから**進めます。
**黙って追加して、後から請求することはありません。**

【要記入：支払いのタイミング（着工時／完工後／分割）と、支払い方法】

## 雨が降ったら

**塗りません。** 濡れた壁に塗っても密着しないからです。

秋田の工事期間中、雨がまったく降らないことはまずありません。
**工期は10日前後と言っていますが、天候で前後します。**
日程に余裕を持ってご計画ください。
