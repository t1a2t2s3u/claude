# カベカルテ 価格設定の検討メモ

2026-08-27 時点の検討内容。販売開始時に見直すこと。

## 結論（推奨価格）

| 形態 | 価格（税込） | 備考 |
|---|---|---|
| サブスク 月払い | **3,300円/月** | 経費で気軽に払える帯の上限 |
| サブスク 年払い | **33,000円/年** | 2ヶ月分お得。こちらに誘導する |
| 買い切り | **88,000円** | サブスク約27ヶ月分 |
| 買い切りの年間更新料 | **11,000円/年（任意）** | 色データ更新・新機能。入らなくても本体は使い続けられる |
| 先行モニター価格 | **1,980円/月（50社限定・ずっと据え置き）** | 導入期に実績と改善の声を集める |
| 無料試用 | 14日 | |

## 相場の根拠（2026-08 調査）

| 近い製品 | 形態 | 価格帯 |
|---|---|---|
| eペイント（カラーシミュレーションWEBアプリ） | 月額 | 1,000円〜 |
| SMAC工事見積など軽量見積ソフト | 月額 | 1,980円〜 |
| 楽王（建築積算・サブスク版） | 月額 | 8,800円〜 |
| カラーシミュレーション専用PCソフト（色彩工房など） | 買い切り | 数万〜数十万円 |
| 建設大臣NXなど大型業務ソフト | 買い切り | 数十万円〜 |

- カベカルテは診断書・見積り・完工報告・カラーシムの4機能入りだが、
  工程管理・原価管理まではない現場特化のライトな道具。
  → 単機能のeペイントより上、積算特化の楽王より下の帯が妥当
- 一人親方の心理的上限は月3,000円台。8,800円になると検討が長引く
- 価値側の根拠: 外壁塗装1件の粗利は20〜30万円。診断書・提案書の質で
  年1件でも受注が増えれば年会費の10倍以上を回収できる
- 原価側の根拠: データは端末内保存でサーバー費ほぼゼロ。
  主なコストはサポート対応の人時

## 買い切りの設計で決めておくこと

- 買い切り価格はサブスク24〜30ヶ月分が定石。安すぎると全員が
  買い切りを選び、サブスク収益が育たない
- **「本体は購入時点の版。以後の色データ更新・新機能は年間更新料（任意）」
  と販売ページに明文化する。** 買い切りは「アップデートはいつまで無料か」で
  必ず揉めるため。塗料の標準色は実際に改定される（シリコンルーフIIの
  サニーレッドは2014年に色相変更）ので、更新料には実利がある

## 販売開始前にやること（価格以外）

1. **ライセンス制御の実装。** 現状の kabekarute.com は誰でも全機能を
   使えてしまう。購入者だけが使える仕組み（ライセンスキー等）が必要。
   Claude に依頼すれば実装する
2. 決済手段（Stripe 等）と特定商取引法に基づく表記
3. 利用規約の整備（現状のランチャーの利用条件を土台に）
4. 商標の確認 → `docs/kabekarute/shohyo.md`
5. noindex の解除 → `docs/kabekarute/deploy.md` のメモ参照
6. できれば周りの同業者に「月いくらなら払うか」を聞いて感触を確認
   してから確定する
