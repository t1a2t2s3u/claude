# 「カベカルテ」商標確認の手順書

売り出す前に必ずやる確認です。所要 30分・確認自体は無料。
スマホでもできますが、パソコンのほうが見やすいです。

## 1. J-PlatPat で先行商標を調べる（無料）

特許庁の公式データベースで、同じ・似ている商標がすでに登録されていないかを
確認します。

1. https://www.j-platpat.inpit.go.jp/ を開く
2. 上のメニューから **「商標」→「商標検索」** を選ぶ
3. 検索項目を **「称呼（単純文字列検索）」** にして `カベカルテ` で検索
4. 続けて、読みの近いものも同じ手順で検索する
   - `カベカルテ` / `kabekarute` / `カベガルテ` / `カベカルデ`
   - 念のため `カルテ` 単独でも検索し、**塗装・建築・アプリ関係**の
     登録がないか眺める
5. それぞれの結果で見るのは **「区分」**（下記）と **「状態」**（存続して
   いるか）。無関係な業種（例: 医療機器）の登録は基本的に問題ない

> 検索結果がゼロ、または関係ない業種だけなら、次の出願に進んで大丈夫です。
> **似た読みで塗装・建築・ソフトウェア関係の登録が見つかったら、そこで
> 止めて弁理士に相談**（初回相談は無料の事務所が多い）。

## 2. どの区分で出すか

商標は「どの商品・サービスに使うか」の区分ごとに登録します。
カベカルテで押さえるべきは次の2つです。

| 区分 | 内容 | カベカルテでの該当 |
|---|---|---|
| **第9類** | ダウンロードできるコンピュータプログラム | 買い切りで配るアプリ本体 |
| **第42類** | インターネット経由で提供するソフトウェア（SaaS） | 将来のサブスク版 |

余裕があれば **第35類**（広告・営業支援）も候補ですが、まずは9類・42類の
2区分で十分です。

## 3. 費用の目安（2026年時点・特許庁に払う法定費用）

- 出願料: **3,400円 ＋ 8,600円 × 区分数**（2区分なら 20,600円）
- 登録料: **32,900円 × 区分数**（10年分。2区分なら 65,800円）
  - 5年ごとの分納も可（17,200円 × 区分数）だが、10年一括のほうが割安

2区分・10年で **合計 86,400円** が特許庁費用の目安。
弁理士やオンラインサービス（Toreru、Cotobox など）に頼むと、これに
手数料（相場: 1区分あたり 1.5〜4万円程度）が乗る代わりに、書類作成と
拒絶対応を任せられます。

> 最新の料金は特許庁のサイトで確認すること:
> https://www.jpo.go.jp/system/process/tesuryo/hyou.html

## 4. 自分で出すか、頼むか

- **自分で出す**: 特許庁の電子出願または書面出願。費用は法定費用のみ。
  ただし商品・役務の指定の書き方に慣れが要る
- **オンラインサービス経由（おすすめ）**: 質問に答えるだけで出願まで
  進める。費用と手間のバランスが良い
- 出願から登録までは **半年〜1年程度** かかる。**出願した日から権利の
  優先順位が決まる**ので、売り出す気持ちが固まったら早めに出すのが安全
