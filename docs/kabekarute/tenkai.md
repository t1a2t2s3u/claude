# カベカルテ 今後の展開の検討メモ

2026-08-27 時点の検討内容。価格は `kakaku.md`、集客は `shukyaku.md`。

## 大前提

**新サービスを増やすより「カベカルテを50社に売る」が先。**
商品を増やすと開発も宣伝も分散して、どれも中途半端になる。
以下は着手順に並べてある。

## ① カベカルテの中に「次の商品」を作る（最有力）

### アフター点検カルテ

塗装完了後の 1年・3年・5年点検の記録をカルテに追記していく機能。

- 塗装店の利: 点検の口実でお客様と接点を持ち続けられる
  → 次の塗り替え（10年後）と紹介の受注装置になる。
  「点検までやってくれる塗装店」は差別化そのもの
- 浅利さんの利: 過去の案件データが溜まるほど解約しにくくなる
  → サブスク継続率が上がる
- 「1軒の家に、1つのカルテ」というコンセプトの完成形

### 小さめの追加案（既存の「入力→A4書類」の型で作れる）

- 保証書テンプレート
- 近隣挨拶文の作成
- 週間工程表

## ② すでに持っている資産の商品化

このリポジトリには売り物になり得るものがもう1つ入っている。
**辰弥塗装工業のサイトとMEOのために作った仕組みそのもの。**

- 「塗装店向けホームページ＋SEO記事の型」パッケージ
  - 施工事例・よくある質問・補助金記事の構成はどの県の塗装店にも通用する
- GBP（Googleビジネスプロフィール）の週次レポートツール
  - `seo_meo` パッケージのMEOレポート機能を製品化する

どちらもカベカルテのユーザー（＝塗装店）にそのまま売れる相性のいい品目。

## ③ 隣接業種への横展開（中期）

同じ設計（スマホ完結・サーバー不要・書類特化）で業種だけ変える。

- **ヤネカルテ**（屋根板金・雨漏り点検）: 診断書文化が最も近く最有力
- 防水工事版／外構・エクステリア版／内装リフォーム版

**注意: カベカルテの説得力の源は「現役の塗装職人が自分の現場で
使っている」こと。** 自分が現場を知らない業種ではこの武器が消える。
やるなら、モニターの中にその業種と兼業の会社が出てきたときに、
その人と組んで作る。

## おすすめの順番

   カルテを開発
2. **来年**: ユーザーが付いたら「サイトの型＋MEOレポート」を追加商品
   として展開
3. **その後**: モニターの声を見て、需要のある隣接業種に横展開
