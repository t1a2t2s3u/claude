## 3. 「写真で見積り」を押されたあと

左上のボタンは、お客様に `写真で見積りをお願いします` と送信させるだけ。
**その後どう返すかは、応答モードで変わる。**

### 応答モードの選び方

| モード | できること | できないこと |
|---|---|---|
| **チャット**（推奨） | 自分の言葉で手動返信 | キーワード自動応答が常時は動かない |
| Bot | キーワードで自動返信 | 手動でのやりとりができない |

**塗装は一件ごとに事情が違うので「チャット」を勧める。** 自動で定型文を
返しても、結局そのあと手で答えることになる。

### 自動で返す場合（Bot モード）

トークルーム管理 → 応答メッセージ → 作成。

| 項目 | 値 |
|---|---|
| タイトル | `写真見積りの案内` |
| キーワード | 下記 |

本文は500文字まで入るので、下の文面をそのまま使える。

**キーワードは完全一致。** 送られたメッセージ全体が一致しないと反応しない
ので、「よくある送り方」を1つずつ登録していく。`見積り` と `見積もり`、
`お` の有無は、それぞれ別に要る。

```
写真で見積りをお願いします   ← リッチメニュー側と一字一句そろえる。必須
見積り
見積もり
お見積り
お見積もり
概算
写真で見積り
見積りお願いします
見積もりお願いします
見積りをお願いします
```

`いくら` を含むものは入れない。**下の「料金」への応答と食い合う。**
同じキーワードを2つの応答に登録すると、どちらが返るか決まらない。

`こんにちは` のような挨拶は入れない。挨拶しただけの人に写真の要求が飛ぶ。
`料金` も入れない（下記の別メッセージで扱う）。

**拾えるのは一部でしかない。** あいさつメッセージに①②③が書いてあるので、
多くの人はボタンを押さずに写真を送ってくる。キーワード応答は取りこぼしを
減らす保険として考える。

## 3-3. 自動応答にしないもの

定型文を返すと、かえって信用を落とす。**人が答えること。**

| 問い | 理由 |
|---|---|
| 建設業許可は持っているか | 未取得。500万円未満の工事に許可が要らないことを、自分の言葉で説明する |
| 保険に入っているか | 未加入。同上。ごまかさない |
| 支払いは分割・カードが使えるか | 実際の対応が未確認。誤案内は契約トラブルになる |
| 火災保険・助成金は使えるか | 適用可否は個別判断。断定すると保険金請求のトラブルに直結する |
| いつから工事できるか | 予約状況で変わる。古い情報は嘘になる |
| 訪問販売に「今すぐ塗れ」と言われた | 不安な状態の人。個別性が高く、受注にもつながりやすい |

**背景画像はサイトのヒーローと同じ写真を使っている。** サイトから来た人が
「同じ会社だ」と一目で分かるようにするため。

> **ここでいう「24時間営業」は受付時間のこと。** LINE はいつでも送れる、
> という意味で 24 時間にしてある。サイトと GBP の営業時間（平日
> 8:00〜20:00／土曜 8:30〜19:00）とは意味が違うので、食い違いではない。
> **返信がいつ来るかは、応答メッセージの文面で伝える**（「一日以内には
> お返事します」）。ここを書かないまま24時間と表示すると、夜中に送って
> 返事が来ない人が「無視された」と受け取る。

> **背景とアカウント名で屋号を混在させない。** 2026-08 の時点で、背景が
> 別屋号「秋田外壁リフォーム本舗」のバナーだった。屋号を複数持つこと自体は
> 問題ないが、1つの窓口の中で名前が2つ出ていると、初めて見た人が別の会社と
> 受け取る。LINE は辰弥塗装工業の窓口として統一する。

設定を変えたら **「保存した内容を公開」** を押すまで反映されない。

## 5. 友だちを増やす導線

**1〜3 ができてから手をつける。** 受け皿がない状態で人を流してもこぼれる。

| 場所 | 状況 |
|---|---|
| サイト（全ページの固定バー） | ✅ 設置済み |
| Google ビジネスプロフィール | ⬜ サイトURLすら未登録。**最優先** |
| 現場の看板・作業車 | ⬜ QRコードを貼る |
| 名刺・お見積書 | ⬜ QRコードを載せる |
| Instagram のプロフィール | ⬜ リンクを置く |

QRコードは `site/assets/line-qr.png` にある。
