## 1. あいさつメッセージ

消費しない**ので、長さを惜しむ理由がない。吹き出し3つに分ける。

会社名だけでなく代表者名を出しているのは、「会社が返してくる」より
「人が返してくる」と感じてもらうため。

## 2. リッチメニュー

トーク画面の下に常に出る。あいさつメッセージが1回しか出ないのに対して、
こちらは**開くたびに目に入る。**

### 画像

- `docs/line/richmenu.png`（2500 × 1686、6分割）
- 作り直すときは `python3 docs/line/richmenu.py`
- 配色はサイトと共通（`site/assets/style.css` の `--brand-deep` / `--accent`）

**押してほしい「写真で見積り」だけオレンジにしてある。** 全部同じ色にすると
どこを押せばいいか分からなくなる。

### 各ボタンの設定

左上から順に。**左上がいちばん押される位置**なので、そこに
いちばん取りたい行動を置く。

| 位置 | ラベル | アクション | 値 |
|---|---|---|---|
| 左上 | 写真で見積り | テキスト | `写真で見積りをお願いします` |
| 中上 | 料金を見る | リンク | `https://tatsumi-tosou.com/services/` |
| 右上 | 施工事例 | リンク | `https://tatsumi-tosou.com/works/` |
| 左下 | 電話する | リンク | `tel:08077065395` |
| 中下 | 会社について | リンク | `https://tatsumi-tosou.com/about/` |
| 右下 | Instagram | リンク | `https://www.instagram.com/tatsumi_tosou_kougyou/` |

> **「テキスト」に入れるのは、お客様が代わりに送信する言葉。** 返信文では
> ない。管理画面の入力欄は **50文字まで**なので、案内文を貼ろうとすると
> 弾かれる。返信は「応答メッセージ」側で設定する（次の節）。

> **`tel:` が管理画面で弾かれた場合**は、アクションを「テキスト」に変えて
> `電話で相談したい` を送らせ、応答（または手動）で番号を返す。トーク内の
> 電話番号はタップで発信できる。

### 表示設定

| 項目 | 値 |
|---|---|
| タイトル（管理用） | `通常メニュー` |
| メニューバーのテキスト | `見積り・料金はこちら` |
| メニューのデフォルト表示 | **表示する**（開いた状態） |
| 期間 | 終了日を設定しない |

## 3. 「写真で見積り」を押されたあと

左上のボタンは、お客様に `写真で見積りをお願いします` と送信させるだけ。
**その後どう返すかは、応答モードで変わる。**

### 応答モードの選び方

| モード | できること | できないこと |
|---|---|---|
| **チャット**（推奨） | 自分の言葉で手動返信 | キーワード自動応答が常時は動かない |
| Bot | キーワードで自動返信 | 手動でのやりとりができない |

**塗装は一件ごとに事情が違うので「チャット」を勧める。** 自動で定型文を
返しても、結局そのあと手で答えることになる。

### 自動で返す場合（Bot モード）

トークルーム管理 → 応答メッセージ → 作成。

| 項目 | 値 |
|---|---|
| タイトル | `写真見積りの案内` |
| キーワード | `写真で見積りをお願いします`（リッチメニュー側と一字一句そろえる） |
| | 併せて `見積り` `見積もり` `概算` も登録しておく |

本文は500文字まで入るので、下の文面をそのまま使える。

### 手動で返す場合（チャットモード・推奨）

チャット画面の「定型文」に入れておけば、ワンタップで送れる。

```
ありがとうございます。
この3つを送ってください。

① お家の写真（正面から1枚）
② お家の写真（斜めから1枚）
③ 建物の縦と横の、だいたいの長さ

長さは「たぶんこれくらい」で大丈夫です。
写真だけ先に送っていただいても構いません。

拝見してから、おおよその金額をお返しします。
現場に出ていると遅くなることがありますが、
一日以内にはお返事します。

辰弥塗装工業　浅利
```

自動返信でも名前を入れておく。「人が見ている」と伝わるほうが、次の
メッセージが送られやすい。

**最後の一文が効く。** 返事がいつ来るか分からない状態が、いちばん不安に
させる。

## 4. 一斉配信

**急いで始めないこと。** 用のない配信はブロックを招く。塗装は年に何度も
買うものではない。

- 春の工事前（1〜2月）
- 秋の工事前（7〜8月）

この年2回、季節の話として送る程度で足りる。ネタは
`site/posts/` のブログ記事から流用できる。

> 配信通数の無料枠と料金プランは変わることがある。実際の上限は
> 管理画面で確認すること。あいさつメッセージと応答メッセージは
> 通数に数えられない。
