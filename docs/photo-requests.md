# 写真の依頼リスト

ブログ記事とサイトに使う写真の依頼をまとめる。**記事を書き始める前に、
ここへ追記して本人に渡すこと。** 撮ってもらえないまま公開すると、
フリー素材で埋めることになり、他社と同じ見た目の記事になる。

> **本人向けのチェックリスト（スマホで開く用）:**
> https://claude.ai/artifact/AX7QcYyqznpZ1vxoJRnqBz
> このファイルと同じ内容を、現場で見てチェックできる形にしたもの。
> 撮影済みのチェックは共有されるので、こちらからも進み具合が読める。
> **このファイルを更新したら、あちらも更新すること。**

> **位置情報は気にせず、スマホでそのまま撮ってよい。**
> `seo-meo photo-prep` が EXIF の位置情報を除去し、幅1600pxに縮小する。
> 工事現場はお客様の自宅なので、この処理を通さずに公開しないこと。

撮るときの共通の注意:

- **明るいうちに撮る。** 曇りでもよいが、夕方以降は避ける
- **寄りと引きの2枚。** 寄りだけだと何の部位か伝わらない
- **お客様の表札・車のナンバー・近隣の家が写り込んでいないか**を確認する
- 前後の比較写真は**同じ位置・同じ角度**で撮る

## 優先度 1 — 雨漏りの記事（10月上旬公開予定）

検索需要が最も大きいテーマ（「雨漏り 秋田市」が全キーワードで表示回数1位）。
サイトに雨漏りの写真が1枚も無い。

| 欲しい写真 | 用途 |
|---|---|
| **天井や壁の雨染み** | サムネイル候補。「これうちだ」と気づいてもらう1枚 |
| **ベランダ・屋上の防水層のひび割れ、水たまり** | 劣化のサインの説明 |
| **切れた・痩せたコーキング** | 水の入り口の説明 |
| **散水調査や原因調査をしている様子** | 「原因を特定してから直す」という主張の裏づけ |
| **軒先のつらら、または屋根の雪庇** | 「すが漏り」の節で使う。雪が融けて軒先で再凍結する様子。冬に撮れればよい |
| **谷板金・棟板金のサビや浮き** | 水の入り口になりやすい6か所の説明で使う |
