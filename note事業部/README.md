# note事業部（休止 — 7人体制へ統合済み）

この体制は 2026-09-06 に、ブランチ `claude/ai-employee-claude-code-d99jvr` の
noteマネタイズチーム（7人体制: 編集長・ライター・校閲・SNS・アナリスト・
リサーチャー・タスク秘書）へ統合された。

- 記事はすべて同ブランチの `articles/` レーンで管理される
  （drafts → ready → published）。ここで書かれた記事2本も移管済み。
- 各メンバーは専用の常設セッションとして稼働し、Routineが定期メッセージを
  配信する。使い捨てセッション方式はプッシュ権限を持てないため廃止。
- 記事の最新状況は引き続き
  [記事ボード](https://claude.ai/code/artifact/787b2d97-717a-4449-bfc4-5563957d94c9)
  で確認できる（ライター・校閲が更新）。

このフォルダと `claude/note-content` ブランチは記録として残すが、
新しい作業はここでは行わない。
