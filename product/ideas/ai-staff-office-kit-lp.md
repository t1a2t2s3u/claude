## 原稿（note 用・無料記事）

---

### タイトル案（どれか1つ）

- A: 非エンジニアの塗装店主が、13人の「AI社員」で会社を回している実物を、キットにして渡します（準備中）
- B: 「AI秘書」の次。秘書・仕上げ担当・監査役の3人から始める「AI社員オフィス」スターターキット
- C: AIに仕事を任せて事故らない仕組みを、そのまま渡します

### 本文

**先に結論**: 私が毎日使っている「AI社員オフィス」を、他の一人経営者が
自分の会社で1日で立ち上げられる形に整えて、買い切りで販売する準備を
しています。**まだ売っていません。** 欲しい人が何人いるかを数えてから
作りたいので、興味がある方は最後の「発売時に通知」から登録してください。

**私について**: 秋田で外壁・屋根塗装の会社をやっています。プログラムは
書けません。2026年8月末から、Claude Code というAIツールに「社員」の
役割を持たせて、本業のホームページ集客と、副業の発信を任せています。
いま13人。毎朝、秘書が今日やることをまとめて届け、記事係が下書きを書き、
校閲係が直し、監査役が「嘘や誇張がないか」を点検します。私は「はい／
いいえ」で答えるだけの日がほとんどです。

【あなたの体験をここに: 始める前に何に困っていたか、いま毎日どれくらい
の時間で回しているか。数字は本当のものだけ】

**なぜキットにするのか**: 「AI秘書の作り方」の記事や無料テンプレは
たくさんあります。私も読みました。でも秘書を1人作っても、会社には
なりませんでした。任せっぱなしにすると、AIは平気で「それらしい嘘」を
書きます。必要だったのは、**任せる係・確認する係・止める係**がそろった
仕組みと、「してはいけないこと」を全員の指示書に最初から入れておくこと
でした。それを一から考えるのに、私は数週間かかりました。その分を
飛ばせるようにします。

**キットに入るもの（初版）**:

1. 管理部3人の指示書 ── 秘書（タスクボード＋朝のブリーフィング）、
   仕上げ担当（あなたに「はい／いいえ」で聞く質問シート）、監査役
   （捏造・誇大・法令リスクの点検）。この3人だけで「任せる→確認する→
   直す」の輪が回ります。
2. オフィスの実物 ── タスクボード、朝礼ボード、質問シートの雛形。
   AI社員が今どこで何をしているかが見えるドット絵のオフィス画面も
   入れる予定です。
3. 導入手順書 ── インストール、会社のルール（CLAUDE.md）、定期実行
   （Routine）の設定、ボードの公開まで。**非エンジニアの私がつまずいた
   所と、その回避策をそのまま書きます。**
4. 「してはいけないこと」集 ── 全社員に共通する禁止事項（嘘を書かない、
   勝手に公開しない、体験談は本人が書く 等）。

13人のフル構成（本業の集客部・副業の編集部・新規事業の企画室）は
上位版として別に用意します。

**必要なもの**: Claude Code が使える claude.ai の有料プラン。定期実行
（Routine）は 1日の実行回数に上限があります（Pro は5回、Max は15回、
Team/Enterprise は25回。2026年9月時点の Anthropic 公式発表。研究プレビュー
中のため変わることがあります）。**3人構成は Pro でも1日1回ずつ回せます。**
13人構成は Max 以上が前提です。

**向いている人 / 向いていない人**:
- 向いている: 従業員0〜5人の経営者・個人事業主。AIを「たまに聞く」
  までは来ていて、業務に組み込みたい人。プログラムは書けなくていい。
- 向いていない: 完全放置で勝手に売上が上がる仕組みを探している人。
  このキットは「あなたが毎日5〜15分、はい／いいえで答える」前提です。

**価格（予定）**: 買い切り 【価格: オーナーが決める。目安 ¥2,980〜4,980】。
発売時に確定します。

## 書いてはいけないこと（監査役の観点）

- 他人の体験（「庶務が90%消えた」等）を自分の実績のように書かない。
- 収益や効果を断定しない（「月◯万円」「◯時間削減」は本当の記録がある
  ものだけ、オーナーが書く）。
- 本業の顧客情報・見積・社名以外の固有情報は載せない。
- Claude Code の仕様（回数上限・プラン）は日付つきで書き、変わりうると
  明記する。
