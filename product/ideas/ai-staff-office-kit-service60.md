## 原稿（ココナラ用。ストアカは末尾の差分を適用）

---

### サービス名（25字前後・どれか1つ）

- A: 非エンジニアのあなたのAI社員を、60分で1人立ち上げます
- B: Claude Code で「AI秘書」を1人、あなたの業務に合わせて一緒に作ります
- C: 13人のAI社員を回している経営者が、最初の1人を60分で作ります

### キャッチコピー（1〜2行）

プログラムは書けなくて大丈夫。あなたの毎日の段取りを聞いて、
Claude Code に「秘書役」を1人作り、毎朝自動で動く状態にして帰ります。

### サービス内容

**こんな方へ**
- 従業員0〜5人の経営者・個人事業主。AIは「たまに聞く」までは来ているが、
  業務に組み込めていない
- 「AI社員」「AI秘書」の記事を読んでやってみたいが、何から始めればいいか
  分からない
- プログラムは書けない（私も書けません）

**私について**
地方で、ネットの外の小さな会社を一人で経営しています。2026年8月末から
Claude Code に「社員」の役割を持たせ、いま13人のAI社員（秘書・記事係・
校閲・監査役など）に本業の集客と副業の発信を任せています。毎朝、秘書が
今日やることをまとめて届け、私は「はい／いいえ」で答えるだけの日が
ほとんどです。
【あなたの体験を1文: 始める前に何に困っていたか。数字は本当のものだけ】

**60分でやること**
1. （10分）あなたの業務を聞く: 毎日・毎週、何に時間を取られているか
2. （35分）画面共有しながら、Claude Code に「秘書役」1人を作る
   - 会社のルール（CLAUDE.md）を一緒に書く
   - 秘書の指示書（スキル）を1本作る
   - 毎朝決まった時刻に動く設定（Routine）を入れる
3. （15分）翌朝から何が届くかを確認し、「してはいけないこと」
   （嘘を書かない・勝手に公開しない・体験は本人が書く）を指示書に入れる

**お渡しするもの**
- 作った CLAUDE.md と秘書の指示書（そのまま使えます）
- 当日の手順メモ（後から自分で2人目を増やせるように）

**事前に必要なもの**
- Claude Code が使える claude.ai の有料プラン（Pro 以上）。定期実行は
  1日の回数上限があります（2026年10月時点: Pro 5回／Max 15回。研究プレビュー
  中のため変わることがあります）。秘書1人なら Pro で足ります
- パソコンと Zoom（またはココナラのビデオチャット）
- インストールがまだの方は、先に無料の公式手順でインストールしておくと
  60分を全部「作る」に使えます（手順はご購入後にお送りします）

**向いていない方**
- 完全放置で売上が上がる仕組みを探している方。このサービスは「毎朝
  5〜15分、はい／いいえで答える」前提です
- プログラムを教わりたい方（コードの講義はしません）

**料金**: ¥5,000（60分・1回）

**よくある質問**
- Q. 本当に非エンジニアでもできますか？
  A. 私自身がそうです。ただし、Claude Code の仕様は月単位で変わるので、
  当日の画面と手順メモが一致しないことがあります。その場合は一緒に
  公式ドキュメントを見ながら進めます。
- Q. 業種は問いますか？
  A. 問いません。秘書役は業種に依りません。
- Q. 60分で終わらなかったら？
  A. 秘書役1人が「翌朝動く」状態を目標にします。当日中にそこまで至ら
  なかった場合は、残りの手順を文書でお渡しします（Claude Code の
  仕様変更や定期実行の回数上限、お使いの環境によって、翌朝動かない
  ことはありえます）。続きを一緒にやりたい場合は追加購入をお願いします。
  【2026-10-21 監査指摘（10/17）で「約束します」から履行できる形に修正】
- Q. 録画はできますか？
  A. ご自身の画面の録画は自由です。

### ストアカ用の差分

- 講座名は30字以内に調整。「【1対1・オンライン】非エンジニアのAI社員を60分で1人立ち上げる」
- 「先生のプロフィール」に活動実績の URL（note）が必要。note の記事公開後に。
- 顔写真が必須。本業が特定されない写真を選ぶ。
- 受講料 ¥5,000。自己集客 URL を使うと手数料 10%【未確認】。

## 書いてはいけないこと（監査役の観点）

- 本業を特定できる情報（社名・業種・地域・施工内容）。「地方で、ネットの
  外の小さな会社」まで。写真も同じ。
- 他人の体験や数字を自分の実績のように書かない。「庶務が90%消えた」等は
  使わない。
- 効果の断定（「必ず」「月◯万円」）。約束するのは「秘書役1人が翌朝動く
  状態」だけ。
- Claude Code の仕様（回数上限・プラン）は日付つきで書く。
