## 解決する不便（誰の、どんな場面の）

**誰**: 従業員0〜5人の経営者・個人事業主で、非エンジニア。ChatGPT や
Claude を「たまに聞く」までは来ているが、業務に組み込めていない人。

**場面**: 「AI社員」「AI秘書」の記事を読んで、やってみたいと思って
Claude Code を入れたところで止まる。理由は
①何を任せればいいか分からない（導入率12%、最大障壁「何から始めれば
いいか分からない」）、②指示書（スキル）を1本書けても「会社として
回す」形にできない、③定期実行・承認・チェックの仕組みを一から考える
時間がない。

## 販路の決定（2026-10-21）

オーナー決定（10-17「チャット対応なし」、10-21「Zoom などの対面サポートは
一切無し」、9-20「本業は明かさない」）を満たす販路の条件は3つ:
**①購入後に人手がいらない（自動配布）／②本名・住所を出さずに済む／
③買い手が迷わず払える。** `reports/2026-10-21.md` 追記の比較表のとおり、

- **note 有料記事に ZIP を添付（本線）**: 購入者は記事内から自動で
  ダウンロード（有料エリア内のファイルが購入者のみになるかは【未確認】、
  出品前にオーナーが編集画面で確認）。note の公式ヘルプは、特商法の
  「販売業者」に当たらない限り住所・電話の掲載は不要、開示請求にも
  応じる義務なしとしている（当たるかどうかの判断は残る【要確認】）。
  手数料は決済 5%＋残額の 10%（¥5,000 → 手取り約 ¥4,275、振込 ¥270/回
  別）。note 編集部の記事がそのまま導線になり、編集長は 9-21 にキットを
  受理済み。読者が note にいる以上、別サイトへ飛ばすより買われやすい。
- **BOOTH（第二）**: 自動配布、5.6%＋45 円（手取り約 ¥4,675）。特商法
  表記は住所・電話を「請求があれば開示」で省略できるが、開示は販売者
  自身が行う（運営の代理表示なし）、氏名欄の扱いは【未確認】。買い手に
  pixiv アカウントが要る。note から買えない人向けの受け皿。
- **STORES（第三）**: 自動配布、5.5%〜。住所・電話は運営会社の情報で
  代替表示できるが、**氏名は表示**される（屋号の可否【未確認】）。
  「本業は明かさない」との相性が一段落ちる。
- **ココナラ（不採用）**: 購入後 48 時間以内に出品者の初回連絡がないと
  自動キャンセル（公式）。「置いておけば売れる」にならない。22%。

## 競合と、そこに勝てる理由

| 競合 | 何が足りないか |
|---|---|
| 無料の「AI秘書テンプレート（設定3分）」（Qiita） | 秘書1人。承認・監査・質問シートがなく、「任せっぱなしで事故る」問題に答えていない |
| 「AI社員の作り方」系の無料解説記事 | 読んで分かるが、実物のファイルがない。組み立ては読者任せ |
| Anthropic 公式のドキュメント・テンプレ | 正確だが汎用。「一人経営者の会社」として組んだ例ではない |
| Brain 等の Claude Code 教材 | 副業・コンテンツ販売向けが中心。小規模事業の業務運用向けは薄い【未確認: 網羅的には未調査】 |
| **Anthropic 公式「Claude Duet」**（2026-10-21 研究プレビュー） | 毎朝のブリーフ・連携アプリの見張り・行動前の承認を公式が提供。ただし**米国の Pro/Max のウェイトリストのみ、日本の提供時期は未発表**。独自の仮想マシンで動き、連携先は Gmail・Slack 等のクラウドアプリ。**手元のファイルや Claude Code のフォルダを扱う記述は公式記事にない**（2026-10-28 確認）。下の「Claude Duet の影響」 |

勝てる理由は2つ。①**会社として回っている実物**（複数部署・監査役・
仕上げ担当・オーナー承認フロー・オフィスボード）を、非エンジニアが
数週間運用した記録つきで渡せる。②「してはいけないこと」（捏造禁止・
勝手に公開しない・体験は本人が書く）が全スキルに入っていて、
初心者がいちばん怖い「AIが勝手に嘘を出す」を最初から潰してある。

勝てるか3点にとどめた理由: 無料競合が多く、Claude Code 側の機能追加
（Routines・Cowork・デスクトップ版）でキットの一部が陳腐化しやすい。

### Claude Duet の影響（2026-10-28 追記）

- 何が起きたか: Anthropic が 2026-10-21 に常時稼働型エージェント
  「Claude Duet」を研究プレビューで公開。公式記事の想定利用者は
  「professionals and small business owners」で、毎朝のブリーフ・連携
  アプリの見張り・送信や支払い前の承認を提供する。キットの「秘書＝毎朝
  の朝礼」と発想が重なる（`strategy/research/2026-10-25.md`、公式
  https://claude.com/resources/articles/claude-duet ）。
- いま重ならない点（公式記事の記述に基づく、2026-10-28 確認）:
  ①米国の Pro/Max のみ、日本の提供時期は未発表。②Duet は自前の仮想マシン
  と連携アプリ（Gmail・Slack・Stripe 等）を見る製品で、**手元のフォルダの
  タスクボードや原稿、事実台帳を扱う記述はない**。③キットの価値の半分は
  秘書でなく**仕上げ担当（【要確認】を質問に変える）と監査役（捏造・誇大
  の点検）**で、Duet にこの役割はない。④Duet はプランの利用枠を消費する
  （無料ではない）。
- スコアの扱い: **勝てるか 3 は据え置き**。ただし次のどちらかが起きたら
  2 に下げて 11 点＝有望ライン割れとして台帳に書き、継続可否をオーナーに
  出す: (a) Duet が日本で提供開始、(b) Duet がローカルフォルダや Claude Code
  のプロジェクトを扱えると公式が発表。
- 売り方への反映（販売ページ原稿を直すときに入れる）: 「公式の AI 秘書
  （Duet）は米国のみ・連携アプリ向け。このキットは今日・日本で・手元の
  ファイルで動く3人（秘書＋仕上げ＋監査）」。Duet を貶めない。編集長が
  10-26 に有料手順書へ同趣旨の1段落追記を指示しており、言い方を揃える。
- クラウド版の回数上限の記述も更新: 2026-09 の公式ブログは「1日 Pro 5回
  ／Max 15回」だったが、2026-10-28 時点の公式ドキュメントには1日上限の
  記載がなく、1時間あたり100回などの上限が書かれている。キット FAQ Q18

## 検証方法（作る前に需要を確かめる手段）

1. **販売ページだけ先に出す**（LP先行）。内容: 何が入っているか・
   誰向けか・価格・「準備中、発売時に通知」ボタン。通知登録の数を見る。
   目安: 2週間で登録が二桁に届かなければ見送り。
2. note編集部の連載記事（無料）の末尾に「キット準備中」の1行を入れて、
   反応（スキ・コメント・登録）を見る。編集長の合意が要る。
3. 同時に、既存の無料テンプレ（Qiita）のコメント欄や X の反応から
   「秘書1人では足りなかった」声があるか探す。

## リスク・不確実な点（正直に）

- **Routine の実行回数上限**: 1日あたり Pro 5回・Max 15回・Team/
  Enterprise 25回（アカウント単位。Anthropic 公式ブログ「Introducing
  routines in Claude Code」で 2026-09-16 に確認済み。研究プレビュー中で
  変更の可能性あり、販売ページには日付つきで書く）。13人構成は Pro
  プランでは回らない。3人構成を初版にした理由の一つ。
  （2026-10-14 監査指摘🟡に対応: 9/16 に確認済みだった【要確認】を
  消し忘れていた）
- **仕様変更**: Claude Code は月単位で機能が変わる。手順書の陳腐化に
  追随する手間（更新の約束をどこまでするか）を決めてから売る。
- **サポート負担**: 非エンジニア向けほど「動かない」問い合わせが来る。
  返金条件と、サポート範囲（手順書の範囲内のみ等）を先に決める。
- **本業の情報が混ざる**: 現リポジトリには辰弥塗装工業の実データが
  ある。一般化時に完全に抜くこと。監査役に一般化版を点検させる。
- **note編集部との重なり**: 編集方針の価格帯は 300〜980円。キットは
  その上。記事＝入口・キット＝本体と整理するか、記事に統合するかは
  オーナーと編集長が決める（タスクボードに掲載済み）。
- **効果の主張**: 「庶務が90%消えた」等の他者の体験を自分の実績の
  ように書かない。自分の運用記録だけを書く。
- **法的**: 販売はデジタル商品の買い切り。特商法表記（販売者情報）が
  必要。note/STORES はプラットフォーム側の表記で足りるか【要確認】。
