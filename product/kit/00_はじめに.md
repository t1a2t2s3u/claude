# AI社員オフィス スターターキット ── はじめに

このキットは、**プログラムを書けない一人経営者**が、Claude Code に3人の
「AI社員」（秘書・仕上げ担当・監査役）を置いて、毎朝「はい／いいえ」で
答えるだけで仕事が回る状態を作るためのファイル一式です。

作ったのは、同じく非エンジニアの一人経営者です。2026年8月末から自分の
会社で13人のAI社員を運用しており、その最初の3人をこのキットにしました。

## 入っているもの

| ファイル | 何か |
|---|---|
| `00_はじめに.md` | この文書 |
| `01_導入手順書.md` | 60〜90分で立ち上げる手順。つまずき所も正直に書いた |
| `02_最初の1週間.md` | Day1〜Day7 にやること |
| `03_よくあるつまずき.md` | FAQ。**本商品にサポートはありません**。困ったらまずここ |
| `CLAUDE.md` | 会社のルール。【 】を埋めるだけ |
| `facts.md` | 自社の事実台帳。AIはここに無い事実を書けない |
| `TASKS.md` | タスクボード（空） |
| `.claude/skills/secretary/` | 秘書の指示書 |
| `.claude/skills/finisher/` | 仕上げ担当の指示書 |
| `.claude/skills/auditor/` | 監査役の指示書 |
| `tasks/` | 定期タスクに貼る文面3本 |
| `reports/` `finishing/` `audit/` `work/` | 各担当の置き場（雛形入り） |
| `付録/` | クラウド版への移し方、オフィスボード（任意・上級） |
| `LICENSE.md` | 利用条件 |

## 3人で何が回るか

| 役 | 毎日何をするか | あなたの作業 |
|---|---|---|
| 秘書 | タスクボードを整え、朝礼（今日やること・対応待ち）を1枚にする | 読む（3分） |
| 仕上げ担当 | AIが書いた物の中の【要確認】を「はい／いいえ」の質問に変える | 答える（5分） |
| 監査役 | 嘘・誇大・法令リスク・ルール違反を点検し、🔴を板に載せる | 週1で読む（5分） |

Claude Code の定期実行は、仕事をやり切れなくても「成功」で終わることが
あります（クラウド版の公式ドキュメントに「結果はセッションがどう終わった
かを示すもので、プロンプトの仕事を完了したかどうかではない」と明記。
https://code.claude.com/docs/en/routines 、2026-10-28 確認。このキットが
使うローカル版のページに同じ文はないが、同じ前提で備える）。だから**確認する係（仕上げ担当）と止める係（監査役）**
を最初から置きます。

## 必要なもの

- Claude Code **デスクトップアプリ**が使える claude.ai の有料プラン
  （Pro 以上）。2026年10月時点。
- Windows か Mac。朝にアプリを開いておけること。
  **定期タスクはアプリが開いていて PC が起きている時だけ動きます。**
  寝ていた分は、起動後に1回だけ追いつき実行されます。
- GitHub は不要です（クラウド版に移す場合のみ必要。付録参照）。

## できないこと・約束しないこと

- **購入後の質問・個別サポートはありません。** 手順書と FAQ の範囲で
  ご判断ください。
- Claude Code の仕様は月単位で変わります。手順書は **2026年◯月時点**の
  画面です。更新は保証しません。【制作時に月を確定】
- 売上や時間削減の効果は約束しません。このキットは「毎日5〜15分、
  はい／いいえで答える」人のための仕組みです。
- AI社員は**あなたの代わりに公開・送信・支払いをしません**。それは
  あなたの仕事として設計してあります。

## 所要時間

- 立ち上げ: 60〜90分（インストール済みなら40分）
- 以後: 毎日 5〜15分
