# 01 導入手順書（60〜90分）

> この手順は Claude Code デスクトップアプリ（2026年◯月時点）の画面に
> 基づきます。画面の文言が違う場合は、公式ドキュメント
> https://code.claude.com/docs/en/desktop-scheduled-tasks を正としてください。
> 【制作メモ: 工程2（オーナーの試運転）で各ステップの実画面と所要時間を確定し、
> つまずきを FAQ に追記する。それまでは「公式ドキュメント準拠の下書き」】

## いちばん大事なコツ

**手順2でフォルダを開いたあとは、分からないことをその場の Claude に
日本語で頼めば進みます。** たとえば「このフォルダの 01_導入手順書.md の
手順3を一緒にやって」「tasks/README.md の3本を、ローカルの定期タスク
として登録して」。Claude はフォルダの中の手順書を読んで、代わりに
やるか、やり方を画面に合わせて教えてくれます。公式ドキュメントも、
定期タスクは「セッションで『毎朝9時にコードレビューを設定して』と
頼むだけでも作れる」と書いています。

## 0. 全体像（5分で読む）

1. デスクトップアプリを入れる
2. 作業フォルダを作り、このキットの中身を置く
3. `CLAUDE.md` と `facts.md` の【 】を埋める（10分）
4. 定期タスクを3本登録する（秘書 8:00／仕上げ担当 12:00／監査役 土曜 10:00）
5. 「今すぐ実行」で初回を動かし、権限の確認を「常に許可」にする
6. 翌朝、`reports/` に朝礼が届いているのを確認する

## 1. デスクトップアプリを入れる（10分）

- claude.ai にログインできる有料プラン（Pro 以上）であることを確認。
- Claude デスクトップアプリをインストールし、**Code タブ**を開く。
- 公式ドキュメントによると、ローカルの定期タスクは **Desktop 1.1.5368 以降**
  で使えます。古い場合はアプリを更新。

つまずき: ターミナル（黒い画面）は使いません。Code タブの画面だけで進みます。

## 2. 作業フォルダを作る（5分）

- 書類フォルダの中に `ai-office` のような名前のフォルダを1つ作る。
  日本語名・スペースは避ける（トラブルの元）。
- このキットの ZIP を展開し、**中身を全部**そのフォルダに入れる
  （`CLAUDE.md` がフォルダ直下に来ること）。
- Code タブでこのフォルダを開く。「このフォルダを信頼しますか」と出たら
  信頼する（定期タスクの保存に必要）。

## 3. 会社のルールを埋める（10分）

- `CLAUDE.md` を開き、【 】を埋める: 会社の呼び名（本名・社名でなくてよい）、
  あなたの呼び名、何の仕事をしているか（一言）、絶対に書かせたくないこと。
- `facts.md` を開き、AIに使わせてよい**事実**だけを書く（屋号・提供して
  いるもの・営業日・連絡先の扱い）。**ここに無い事実は AI が書けない**
  ルールです。空でも動きますが、監査役が何でも「捏造」扱いにします。
- 自分でファイルを編集するのが不安なら、Code タブの入力欄にこう頼む:
  「CLAUDE.md と facts.md の【 】を、私に質問しながら埋めて。推測で
  埋めないで」。Claude が1つずつ聞いてきます。

## 4. 定期タスクを3本登録する（15分）

**近道**: Code タブの入力欄に次を貼る。

```
tasks/README.md にある3本（secretary・finisher・auditor）を、このフォルダを
作業フォルダにしたローカルの定期タスクとして登録して。時刻は README の表の
とおり。Worktree はオフ。登録できたら3本の名前と次回実行時刻を教えて。
```

Claude が登録してくれます。うまくいかない場合だけ、下の手動手順へ。

**手動**（公式ドキュメント https://code.claude.com/docs/en/desktop-scheduled-tasks
、2026-10-28 確認）: Code タブの左の **Scheduled**（または More › Scheduled）
→ **New task**。「Create with Claude／Set up manually」と出たら
**Set up manually**。ダイアログの **Advanced settings** を開き、General
タブの **Only on this computer** をオン → **Local folder** でフォルダを選ぶ
→ Trigger で時刻 → **Create**。
古いアプリでは同じ場所が **Routines** → **New routine** → **Local** と
表示されます（公式ドキュメントの注記）。読み替えてください。
1本ずつ、次のとおり入れる。文面は `tasks/` にコピペ用があります。

| # | Name | Schedule | Instructions |
|---|---|---|---|
| 1 | secretary | Daily 8:00（平日だけなら Weekdays） | `tasks/01_secretary.md` の本文 |
| 2 | finisher | Daily 12:00 | `tasks/02_finisher.md` の本文 |
| 3 | auditor | Weekly 土曜 10:00 | `tasks/03_auditor.md` の本文 |

共通設定:
- 作業フォルダ: 手順2のフォルダ
- Worktree（隔離）: **オフ**（ボードや報告ファイルを直接書くため）
- 権限モード: 初回は確認ありで。手順5で「常に許可」にする
- モデル: 既定のままでよい

つまずき: Name は英小文字にする（フォルダ名に使われる）。

## 5. 初回を動かして、権限を覚えさせる（15分）

1. **Scheduled** 一覧で `secretary` を開き **Run now**。実行は詳細ページの
   **History** に1行ずつ出る（サイドバーに「Scheduled」グループが出る
   配置もある。公式ドキュメント 2026-10-28 確認）。
2. ファイルを書く・読む等の確認が出たら **「常に許可」** を選ぶ。
   公式ドキュメントも「作成直後に Run now で権限プロンプトを出し、
   always allow を選ぶ」ことを勧めています。これをしないと、以後の
   実行が確認待ちで止まります。
3. 終わったら `reports/` に今日の日付のファイルができているか確認。
   `TASKS.md` が空なら「今日は登録タスクなし」と書かれているはずです。
4. `finisher`、`auditor` も同様に Run now → 常に許可。

## 6. 最初のタスクを入れる（5分）

`TASKS.md` の 📥 Inbox に、あなたの本当の用事を2〜3行書く:

```
- [ ] 来週の請求書を出す （期限: 2026-◯◯-◯◯ / 優先: 高）
- [ ] ホームページのお知らせを1本書く （優先: 中）
```

翌朝の朝礼に、これが並び替えられて出てきます。

## 7. 翌朝（3分）

- 8:00 以降にアプリを開いていれば、`reports/YYYY-MM-DD.md` に朝礼が
  できています。読んで、やることをやる。
- PC が寝ていた場合は、起動後に1回だけ追いつき実行されます（公式仕様）。
  朝礼が「夜に届く」ことがあるのはこのためです。

## 8. やらなくていいこと

- GitHub、ターミナル、コマンド、API キー。どれも不要です。
- オフィスボード（AI社員の様子が見えるページ）は付録です。動いてから。

## 9. 止めたいとき

**Scheduled** 一覧（古いアプリでは Routines）で各タスクの詳細ページを開き、
**Status** を Active → **Paused** にする。削除する場合は **Delete**。
公式ドキュメント（2026-10-28 確認）によると、削除しても設定ファイル
`~/.claude/scheduled-tasks/<名前>/SKILL.md` のフォルダは残るので、
消したければ自分で削除します。
