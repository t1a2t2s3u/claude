# 03 よくあるつまずき（FAQ）

本商品にサポートはありません。困ったら、まずここを上から読んでください。
公式の情報源: Claude Code ドキュメント https://code.claude.com/docs/
（定期タスク: /docs/en/desktop-scheduled-tasks、スキル: /docs/en/skills）

> 【制作メモ: 工程2（オーナーの試運転）で実際に起きたつまずきを上に
> 足して25問以上にする。以下は公式ドキュメントから書いた初版】

## 定期タスクが動かない

**Q1. 朝8時に何も起きない。**
A. アプリが開いていましたか。ローカルの定期タスクは**アプリが開いていて
PC が起きている時だけ**動きます（公式仕様）。寝ていた場合は、起動後に
1回だけ追いつき実行されます。毎朝確実に動かしたいなら、PC をスリープ
させない設定（Settings › This computer › System › Keep computer awake）に
するか、付録のクラウド版に移します。

**Q2. 「Scheduled」欄にセッションは出るが、途中で止まっている。**
A. 権限の確認待ちです。そのセッションを開いて、出ている確認に
「常に許可」を選ぶ。以後は止まりません。

**Q3. 実行は緑で終わったのに、朝礼ファイルがない。**
A. 「成功」は「セッションがエラーなく終わった」の意味で、頼んだ仕事を
やり切った保証ではありません。**クラウド版（定期タスク／旧 Routines）の
公式ドキュメント**が「結果はセッションがどう終わったかを示すもので、
プロンプトの仕事を完了したかどうかではない。実行を開いて記録を読む」
と書いています（ https://code.claude.com/docs/en/routines 、2026-10-28
確認）。ローカル版のページに同じ文はありませんが、キットは同じ前提で
確認係を置きます。実行の **History** からセッションを開いて何をしたか読む。多くは
「TASKS.md が見つからない」「フォルダが違う」です。作業フォルダが
`CLAUDE.md` のある場所になっているか確認。

**Q4. 同じ日に2回動いた／夜に動いた。**
A. 追いつき実行です。公式仕様で、起動時に直近7日の未実行分のうち
最新の1回だけ実行されます。朝礼の文面に「夜に届いた場合は明日の
準備として読む」と書いてあるのはこのためです。

**Q5. 「Only on this computer」も「Local」も出ない。**
A. デスクトップアプリが古い可能性（公式: ローカルの定期タスクは
1.1.5368 以降、2026-10-28 確認）。アプリを更新してください。更新後も
出ない場合は、リポジトリや GitHub／API のトリガーを選んでいないか確認
（それらを選ぶとクラウド版になり、このスイッチが使えません。公式
ドキュメントの記述）。

## 秘書

**Q6. 朝礼が「今日は登録タスクなし」しか言わない。**
A. `TASKS.md` に用事が入っていません。📥 Inbox に1行書く。
書式は `- [ ] 用事 （期限: 2026-◯◯-◯◯ / 優先: 高）`。期限・優先は
分かる分だけで可。

**Q7. 秘書が勝手にタスクを消した。**
A. 指示書で禁止しています。完了から2週間を過ぎた✅の削除だけは
許可しているので、それでなければ `audit/` の次回報告で🔴になります。
気になる場合は `.claude/skills/secretary/SKILL.md` の「してはいけないこと」
を読み、必要なら1行足す。

**Q8. 秘書に用事を頼むにはどうする。**
A. Code タブで作業フォルダを開いたセッションで、普通に「来週の請求書を
出さないと」と話す。秘書のスキルが使われて板に載ります。使われない時は
「秘書として TASKS.md に載せて」と言う。

## 仕上げ担当

**Q9. 質問シートが空のまま。**
A. 仕上げ担当が見るのは `work/`、`reports/`、`TASKS.md` の中の
`【要確認…】` `【あなたの体験をここに…】` `【未確認…】` だけです。
AIに作らせた文書を `work/` に保存していないと、質問は出ません。

**Q10. 答えたのに本文が変わらない。**
A. 回答は「Q1 はい、Q2 いいえ」の形でチャットから仕上げ担当に送ります。
定期タスクは質問を作るだけで、反映は会話で頼んだ時に行います。

**Q11. 答えていないのに勝手に埋まった。**
A. 仕上げ担当は「無回答＝削除か一般表現に置換」で処理します。
**事実を創作することは禁止**しています。もし固有名詞や数字が増えて
いたら、指示書違反なので監査役が拾います。その文書は使わないこと。

## 監査役

**Q12. 監査役が全部「捏造」と言う。**
A. `facts.md` が空だからです。AIに使わせてよい事実（屋号・提供物・
営業日 等）を書く。ここに無い事実は捏造扱い、が監査の基準です。

**Q13. 🔴が出た。どうする。**
A. `TASKS.md` の Inbox に【監査】タスクとして載っているので、朝礼の
先頭に出ます。該当の文書を直すか、使わない。監査役は人の文書を
書き換えません（法令リスクが明白な箇所に「【監査保留】」を付けるだけ）。

**Q14. 監査役が指示書を変えろと言う。**
A. 提案だけです。採用するかはあなたが決め、`SKILL.md` に1行足す。

## ファイル・フォルダ

**Q15. `CLAUDE.md` の【 】を埋め忘れた。**
A. 動きますが、秘書が会社名を「【会社の呼び名】」のまま書きます。
いつでも埋め直せます。

**Q16. フォルダを移動したら動かなくなった。**
A. 各定期タスクの Edit で作業フォルダを新しい場所に変える。

**Q17. ファイルを間違って消した。**
A. キットの ZIP から該当ファイルだけ戻す。`TASKS.md` を消した場合は
空の雛形を戻せば秘書が動きます（中身は戻りません。バックアップは
あなたの責任です。フォルダを git 管理にすると履歴が残ります。任意）。

## お金・プラン

**Q18. Pro で足りますか。**
A. 3人構成はローカルの定期タスクです。クラウド版の定期タスクには回数の
上限があります（2026年9月の Anthropic 公式ブログでは1日 Pro 5回／Max
15回。2026-10-28 時点の公式ドキュメント https://code.claude.com/docs/en/routines
には1日の上限の記載はなく、1時間あたり100回などの上限が書かれています。
研究プレビュー中で変わります）。**ローカル版にその上限が当てはまるかどうか
は公式ページに記載がありません**（ https://code.claude.com/docs/en/desktop-scheduled-tasks
、2026-10-28 確認。クラウド版とは別の仕組みという理解）。通常の利用量
上限（5時間・週）は消費します。1日3回の短い実行なら Pro で足りる想定
ですが、あなたの他の利用量次第です。

**Q19. クラウド版（PC を閉じていても動く）にしたい。**
A. 付録「クラウド版への移し方」。GitHub アカウントと空のリポジトリが
必要で、クラウド版の回数上限（Q18）が付きます。

## 仕様変更

**Q20. 画面の文言が手順書と違う。**
A. Claude Code は月単位で変わります。手順書は 2026年◯月時点です。
公式ドキュメント（上記 URL）を正として読み替えてください。
更新版の提供は約束していません。
