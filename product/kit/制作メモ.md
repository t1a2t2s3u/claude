## リポジトリ内での置き方（納品時に戻す）

- キットのスキルは、このリポジトリでは `product/kit/dot-claude/skills/` に
  置いている。`.claude/` のままだと Claude Code がこの作業場の「スコープ付き
  スキル」として検出し、本物の秘書・監査役と混ざるため。
- **ZIP 化するときに `dot-claude` → `.claude` に改名する。** 手順書・FAQ・
  CLAUDE.md の記述は購入者向けに `.claude/skills/` のままで正しい。

## ZIP の作り方（試運転用・納品用とも同じ）

```
cp -r product/kit /tmp/ai-office && cd /tmp && mv ai-office/dot-claude ai-office/.claude \
  && rm ai-office/制作メモ.md && zip -qr ai-office-kit.zip ai-office
```

展開すると `ai-office/` フォルダ1つ。その中に `CLAUDE.md` と `.claude/` が
ある状態が正しい。2026-10-17 に試運転用の ZIP をオーナーへ送付済み。
