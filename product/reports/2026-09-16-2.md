# プロダクト調査 2026-09-16（臨時・オーナー依頼）

オーナー依頼「塗装などの建設業にこだわらずに、自分にできそうな企画を
探してきて」への回答。定期稼働ではなく臨時。

前提を置き直した。オーナーが**いま実際に持っている武器**は3つ:

1. 非エンジニアなのに、Claude Code で13人のAI社員（スキル＋Routine＋
   ボード）を数週間運用している当事者。しかも本業（塗装店）で使っている。
2. note × SNS でその運用を発信する体制（編集部）がすでにある。
3. 地方（秋田）の小規模事業者で、同じ立場の経営者の言葉が分かる。

この3つが同時に効く企画だけを探した。

**結論: 1件が 12点で「有望」。** 初めて企画メモを作った
（`product/ideas/ai-staff-office-kit.md`）。ただし note編集部の有料記事
レーンと重なるので、進め方はオーナーと編集長の判断がいる。

スコアは 作れるか / 売れるか / 勝てるか（各5点）。

## 今週の推し（1件）

- **案件名**: 「AI社員オフィス」スターターキット ── 非エンジニアの
  一人経営者が、自分のAI社員チームを1日で立ち上げるための実物一式
  （指示書13本・タスクボード・オフィスボード等のHTML・質問シート・
  Routine の設定手順・「してはいけないこと」集）＋導入手順書
- **スコア**: 12点（作れる5 / 売れる4 / 勝てる3）→ **有望**
- **なぜ今か**:
  - 中小企業のAI導入率は12%で、最大の障壁は「何から始めればいいか
    分からない」。必要なのは「業務フローを理解したうえで具体的に提案
    してくれる相談相手」（出典 1, 2）。
  - 九州大学の Claude Code ハンズオンを「一人でもプロダクトを作れる
    ワークショップキット」として公開した投稿は表示9万回超・保存約1,800件。
    「面白い」より「あとで実際に使いたい」が勝っているサイン（出典 3）。
    **無料のキットでこの反応**なので、需要の存在は確か。
  - お金を払う前例: 国内の Notion テンプレ販売で「個人事業主の経理管理
    ¥3,980」「週次レビュー×AI日報 ¥1,980」等が売られ、初心者が2か月で
    50件超の購入・約10万円の売上を公開している（出典 4, 5）。Brain では
    Claude Code 系教材が ¥4,980 で流通（出典 6）。
  - オーナーは「作らなくていい」。**すでに動いている実物**を、個人情報を
    抜いて一般化するだけ。作れるか5点の根拠。
- **最初に作る最小版**（3つまで）:
  1. キット本体: このリポジトリの汎用版（秘書・仕上げ担当・監査役の
     3人から始まる「管理部だけ」構成。13人は上位版）。
  2. 導入手順書: インストール→CLAUDE.md→Routine設定→ボード公開まで、
     非エンジニアの実話ベース（つまずいた所を隠さない）。
  3. 販売ページ1枚（note か STORES）。**先にこれだけ出して反応を見る。**
- **想定課金**: 買い切り ¥2,980〜¥4,980（Notion テンプレ・Brain 教材の
  実勢に合わせる）。上位に「導入サポート（Zoom 60分）」を付ける案あり。
  **収益予測は断定しない。** 類似事例は上記のとおり。
- **競合と勝ち筋**: 無料の「AI秘書テンプレート（設定3分）」が Qiita に
  あり（出典 7）、「AI社員の作り方 5ステップ」等の無料解説も多い
  （出典 8, 9）。勝ち筋は「秘書1人」ではなく**「会社として回っている
  実物」**（複数部署・監査役・仕上げ担当・オーナーの承認フロー・ボード）
  と、非エンジニアが数週間運用した記録。勝てるか3点は、無料競合の多さと
  Claude Code 側の仕様変更の速さを織り込んだ。
- **重要な注意**: note編集部の編集方針は「手順書・設定ファイル・
  テンプレート集を 300〜980円で」。キットはその上位価格帯の「実物」で、
  記事と競合しうる。**記事＝入口、キット＝本体**と整理するか、記事に
  統合するかは編集長とオーナーの判断（タスクボードに掲載）。
- **リスク**（企画メモに詳述）: Routine の実行回数上限（Pro 1日5回、
  Max 15回という記述あり【要確認】。13人構成は Pro では回らない）、
  Claude Code の仕様変更、購入者サポートの負担、本業の情報が混ざる
  リスク（一般化時に完全に抜く）。

## その他の候補（スコア順）

### 副業クリエイターの収益台帳（note・Kindle・ココナラ等のCSV → 帳簿）— 10点（5/2/3）
- 先週の「note売上CSV→帳簿変換」を複数プラットフォームに広げた形。
  会計士・税理士が「手数料控除後の入金額で記帳すると税務調査で指摘」と
  警告しており不便は本物（出典 10）。ただし推奨解は既存の会計ソフト
  （freee・マネーフォワード等）で、年1回の作業。**note編集部の記事ネタ**
  としての価値の方が高い（前回と同じ結論）。

### Notion テンプレート販売（個人事業主向け業務系）— 9点（4/3/2）
- 売れている前例は上記のとおり。ただしマーケットプレイスは3万点超
  （出典 11）で、オーナー固有の角度がない。**キットの一部（タスクボード・
  質問シート）を Notion 版で出す**なら、上のキットの派生として扱う。

### 地方の小規模事業者向け「AI導入の相談相手」（サービス）— 参考
- 需要の証拠は強い（出典 1, 2）が、アプリ・ツールではなく時間を売る
  サービス。キットの上位プラン「導入サポート」として同梱する形で
  企画メモに書いた。単体のサービス化はスコープ外。
