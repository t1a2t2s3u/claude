# Sonae（そなえ）

毎月の支払いと税金に、そなえる。
個人事業主・フリーランスのための、支払い管理と税金の目安アプリです。

**→ https://t1a2t2s3u.github.io/sonae/**

スマホのブラウザで開いて、「ホーム画面に追加」するとアプリのように使えます。

## できること

- **支払い** — 家賃・光熱費・サブスクなど毎月の固定費を登録して、支払日を
  カレンダーと一覧で見る。仕事で使っている割合（家事按分）を決めると、
  そのぶんが自動で経費になります。
- **仕事の収支** — 収入と経費を日付・科目つきで記録。月別のグラフ、年間の
  一覧、未入金の管理、請求書づくり、銀行やカードの明細CSVの取り込み。
- **税金の目安** — 所得税・住民税・個人事業税・消費税・国民年金・国民健康保険を
  まとめて概算。納付スケジュール、納税用の積立、節税のヒント、確定申告の
  決算書に書き写せる科目別の集計まで。

## データはどこにあるか

**入力した内容は、使っている端末のブラウザの中だけに保存されます。**
サーバーには送られません。作者を含め、誰も見ることはできません。

そのぶん、次の場合は消えます。

- ブラウザのデータ（サイトデータ）を削除したとき
- 端末を買い替えたとき
- プライベートブラウズで使ったとき

**「データと設定」からときどきバックアップを書き出してください。**
書き出したJSONファイルは、別の端末の「ファイルから復元」で読み込めます。
機種変更のときはこれで引き継げます。

ひとつのURLを何人で使っても、データが混ざることはありません。
保存先がそれぞれのブラウザだからです。

## 計算結果について

表示される税額・保険料・節税のヒントは、入力された金額と公表されている
税率・料率から機械的に計算した**概算**であり、**税務相談ではありません**。
実際の税額は、控除の適用、所得の区分、自治体ごとの料率、年度ごとの制度改正に
よって変わります。申告・納付の前に、必ず税務署・自治体・税理士にご確認ください。
計算結果を用いたことによる損害について、作者は責任を負いません。

詳しい前提はアプリ内の「このアプリについて」に書いてあります。

## 技術的なこと

ビルド工程も実行時の依存もありません。`index.html` 1枚にHTML・CSS・JavaScriptが
すべて入っています（外部から読むのは Google Fonts だけ）。

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | オフラインで起動するためのキャッシュ |
| `icon-*.png` | アイコン |

自分で動かすなら、このフォルダをHTTPSの静的ホスティングに置くだけです
（Service Worker を使うので `file://` 直開きと平文HTTPでは
PWAとして動きません。`localhost` は例外）。

`index.html` を更新したら、`sw.js` の `CACHE = 'sonae-v1'` の数字を上げてください。
