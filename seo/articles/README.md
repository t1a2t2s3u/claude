# seo/articles/ — 塗装ブログ記事の流れ

ブログライター（`.claude/skills/seo-writer/`）が書く、ホームページ
（https://tatsumi-tosou.com/blog/）向けの記事の置き場です。

```
seo/briefs/            ← ディレクターの執筆指示（狙う検索語・構成）
seo/articles/drafts/   ← 記事本体（サイト形式 .md）＋ メモ（.memo.md）
                          状態: 確認待ち → 公開OK → 公開済み
seo/articles/published/← 公開した記事のコピーとメモ（URL付き）
```

**公開はオーナーのOKが出てから。** 記事はブログ記事ボード
（CLAUDE.md の「Blog board」）に確認待ちで並びます。オーナーがチャットで
「ブログ <スラッグ> OK」または「修正: …」と返すと、ライターが公開作業
（別ブランチ `claude/seo-meo-automation-mvntxp` の `site/posts/` へ入稿・
ビルド・push）を行います。

## 更新のペース（2026-10-14 オーナー決定。9/15 月3本 → 10/14 月4本）

- **新規記事は月4本「納品」する（毎週1本）。** これが最優先の約束。
  ディレクターのブリーフ1本につき1記事
- **4本目は「写真が要らないテーマ」に固定する。** 本数を増やすと1本あたりの
  写真が薄くなるため、現場の写真は残り3本に集中させる（オーナーの条件）。
  サイト側ネタ帳の「未着手・写真不要」の行から取り、**写真の依頼は増やさない**
- **加筆（公開済み記事のリライト）は月1本。** 新規4本が済んでから。
  **新規4本を割ってまで加筆はしない**
- 月の納品は**合計5本**
- ライターの稼働は火曜。**公開作業はその回の仕事に数えない**
  （公開だけで終わらせず、同じ回に執筆まで進む）
- **本数は「納品日」で数える。公開日でもファイル名の年月でもない。**
  下の一覧の「公開日」とは別物なので注意（例: 雨漏り記事は 10/6 公開だが
  納品は 9/24 なので9月の1本）
