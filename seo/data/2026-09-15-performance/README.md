## 読み取れること

**1. 表示回数は完全に横ばい（1日15.8回）**

3つの期間すべてで1日あたりの表示がまったく同じ。この間にブログを2本
（補助金の追記・色選び）増やしているが、表示は1回も増えていない。
**記事が検索に出ていないことの裏づけ。**

**2. 一覧に出た28クエリすべてクリック0**

14日分のときと同じ傾向が、20日分に延ばしても変わらなかった。誤差ではない。
9クリックはすべて Google が匿名化した検索語から発生している。

**掲載順位1位で0クリックのクエリが7つある**:
外壁塗装 秋田市(18表示) / 屋根塗装 秋田市(9) / 塗装業者 秋田市(6) /
塗装会社 秋田市(5) / 外装リフォーム 秋田市(3) / 外壁業者(1) / 秋田 外壁塗装(1)

地域名の検索では地図枠が画面上部を占めるため、自然検索1位でも実質的に
見えていない、という見立てを補強する材料（→ MEO強化が最優先）。

**3. 表示されているページはトップ1枚だけ（20日間）**

`ページ.csv` の行は2つしかない。
- `https://tatsumi-tosou.com/` … 7クリック / 316表示
- `http://tatsumi-tosou.com/` … 2クリック / 2表示

**ブログ記事の表示は20日間で0件。** 公開済み3本（塗り替え時期 8/23、
補助金 8/26、色選び 9/7）が一度も検索結果に出ていない。
9/15 のインデックス未登録の件（`seo/data/2026-09-15-coverage/`）が、
そのまま集客の機会損失になっていることが数字で確認できた。
