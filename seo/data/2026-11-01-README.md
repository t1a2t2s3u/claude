## 読むときの注意

- **期間が「過去3か月間」なので、前回（2026-10-04 取得）と総数を直接比べられません。**
  重なった期間が入ります。前回との比較は**日別チャートから同じ日数で切り出す**こと
  （10/4〜10/30 の27日 対 9/7〜10/3 の27日、というように）
- **クエリ別のクリック数の合計（6）は、全体のクリック数（72）と一致しません。**
  Google は検索数の少ないクエリを伏せるため。クエリ表は「どんな言葉で表示されたか」を
  見るもので、クリックの内訳には使えない
- **10/21 と 10/27 のクリックは、自分たちのクリックを含む可能性が高い**
  （10/21 はオーナーが Search Console で `/hosho/` `/shindan/` の登録を
  リクエストした日。平均掲載順位 55.4 位で7クリックは通常ありえない）。
  傾向を見るときはこの2日を外して計算する
