# 用語メモ（Search Console・SEO/MEO）

週次レポートやデータの読み取りで出てくる言葉の意味です。
**AI社員へ**: レポートでこれらの語を使うときは、初出で一言かみ砕くこと。

## Search Console の4つの数字

検索パフォーマンスの表には必ずこの4つが並びます。

| 用語 | 意味 |
|---|---|
| **表示回数** | 検索結果に出た回数。見られた回数ではなく「並んだ回数」 |
| **クリック数** | そこから実際に押された回数 |
| **CTR** | クリック数 ÷ 表示回数。「出たうち何％が押されたか」 |
| **掲載順位** | 検索結果での**平均の位置**。1に近いほど上 |

**掲載順位は「表示回数のランキング」ではありません。** 別々の数字です。
表示が多くても順位が低いことも、表示は少ないが1位のこともあります。

例（2026-09-15 のデータ）:

| クエリ | 表示回数 | 掲載順位 |
|---|---|---|
| 外壁塗装 秋田市 | 18 | 1 |
| 雨漏り 秋田市 | 12 | 9 |
| 外装リフォーム 秋田市 | 3 | 1 |

**掲載順位が数えているのは自然検索（広告でない普通の検索結果）の中だけ**で、
地図枠と広告は含まれません。そのため**掲載順位1位でも、画面では広告と
地図枠の下にあってスクロールしないと見えない**ことがあります。
当社で「1位なのにクリック0」が起きているのは、これが原因の可能性が高い
（→ だから順位を上げる施策ではなくMEO強化が最優先）。

## インデックス関連

| 用語 | 意味 |
|---|---|
| **クロール** | Google のロボットがページを見に来ること |
| **インデックス** | 見に来たページを検索結果に載せる候補として登録すること |
| **検出 - インデックス未登録** | URLの存在は知っているが、**まだ見に来ていない**。中身を評価して落としたわけではない |
| **クロール済み - インデックス未登録** | 見に来たが、載せる価値がないと判断された。上とは意味が違う |
| **前回のクロール 1970-01-01** | 日付が入っていない＝**一度も見に来ていない**ということ |
| **サイトマップ** | 「ここにページがあります」と伝える一覧ファイル。伝えるだけで、クロールを強制するものではない |
| **URL検査 → インデックス登録をリクエスト** | 「このページを見に来てください」と個別にお願いする機能。1日10本程度が上限 |

## 地図検索（MEO）関連

| 用語 | 意味 |
|---|---|
| **MEO** | Google マップ・地図枠での見え方を良くする取り組み |
| **地図枠（マップパック）** | 地域名で検索したとき、検索結果の上のほうに出る地図と3件の店舗一覧 |
| **GBP（Google ビジネスプロフィール）** | 地図枠に出る情報の登録元。投稿の新しさ・写真の量・口コミの数と新しさが評価される |
| **NAP** | 店名・住所・電話番号。サイトとGBPで表記を揃えることが大事 |

## 記事・キーワード関連

| 用語 | 意味 |
|---|---|
| **クエリ（検索語）** | 実際に検索窓に打ち込まれた言葉 |
| **title / description** | 検索結果に出る見出しと説明文。クリックするかどうかを決める部分 |
| **スラッグ** | URLの末尾部分。`/blog/2026-09-gaiheki-20nen/` の `2026-09-gaiheki-20nen` |
| **内部リンク** | 自分のサイト内のページ同士をつなぐリンク。クロールの通り道にもなる |
| **加筆（リライト）** | 公開済み記事に、実際に検索された言葉への答えを足して厚くすること |
| **E-E-A-T** | 経験・専門性・権威性・信頼性。実物の写真や一次情報が効く理由 |
