# 写真リクエスト一覧（オーナー撮影用）

ブログ記事・Googleビジネスプロフィール投稿・Instagram で共通して使う写真の
「欲しいものリスト」です。撮影のたびにこのファイルを見ながら潰してください。

**1回の現場でここに載っているものをまとめて撮っておくと、ブログ・GBP・
Instagram の3つに使い回せます。**

撮影できたものは `- [x]` に変え、写真の置き場所（フォルダ名やアルバムURL）を
行の末尾にメモしてください。

---

## 優先度A：これがないと記事の説得力が出ない

- [ ] **ビフォーアフター（外壁）** — 同じ立ち位置・同じ画角で施工前と施工後
- [ ] **ビフォーアフター（屋根）** — 同上。屋根は「見えない場所」なので価値が高い
- [ ] **劣化症状の実物アップ** — 1症状につき1枚、寄りで
  - [ ] チョーキング（手でこすって白い粉がつく様子。手のひらが写ると分かりやすい）
  - [ ] 外壁のひび割れ（細いもの／太いもの、両方あると比較できる）
  - [ ] 塗膜の膨れ・剥がれ
  - [ ] シーリング（コーキング）の切れ・肉やせ
  - [ ] 北面の苔・藻・黒ずみ
  - [ ] 屋根の色あせ、サビ、棟板金の浮き・釘の抜け
  - [ ] （あれば）凍害で表面がボロボロに崩れた外壁 ← **秋田ならではの記事に必須**
- [ ] **塗装の工程** — 「3回塗り」を説明する記事で毎回使います
  - [ ] 高圧洗浄
  - [ ] 養生（マスカーを貼った状態）
  - [ ] ケレン・下地処理
  - [ ] 下塗り／中塗り／上塗り（できれば同じ面で3枚。色が変わるので分かる）
  - [ ] 足場が組まれた家の全景

## 優先度B：信頼につながる写真

- [ ] **職人が作業している姿**（引きの写真。人が写ると一気に「実在感」が出ます）
- [ ] **現地調査・点検の様子**（屋根に上がっている、外壁を触って診断している等）
- [ ] **社用車**（社名が入っていれば地域の人が「見たことある」となります）
- [ ] **使用した塗料の缶**（メーカー名・商品名が読める状態で。記事に商品名を
      書けるようになります）
- [ ] **道具・機材**（高圧洗浄機、刷毛・ローラー、飛散防止ネットなど）
- [ ] **顔写真**（代表者。抵抗がなければ1枚。問い合わせのハードルが下がります）

## 優先度C：あると記事の幅が広がる

- [ ] 冬の現場・雪が積もった家の外観（季節の記事で使えます）
- [ ] 見積書や診断報告書（金額は隠してOK。「こういう書面を出します」の証明）
- [ ] 施工後にお客様と一緒に写った写真（**掲載許可を取れた場合のみ**）

---

## 撮り方のコツ

- **ビフォーアフターは条件を揃える。** 同じ立ち位置・同じ画角・できれば同じ
  天気と時間帯。バラバラだと「本当に同じ家？」と疑われて逆効果です。
- **加工しない。** 色を派手にしたり汚れを消したりすると、景品表示法上の
  リスクになります。明るさの微調整までにしてください。
- **明るい時間帯に、逆光を避けて。** 曇りの日はむしろ色が正確に写ります。
- **横向きと縦向きの両方を撮る。** ブログは横長、GBP・Instagram は正方形〜縦長が
  向いています。1シーンにつき両方あると使い回せます。
- **寄りと引きをセットで。** 症状は寄り、家全体は引き。
- **スマホでそのままでOK。** 一眼は不要です。ただしレンズの汚れだけ拭いてください。

## 撮ったらメモしてほしいこと（写真と一緒に）

これがないと記事に説明が書けず、`【要確認】` が増えます。

- 撮影日
- 施工した地域（**市・町のレベルまで。番地や表札が分かる情報は不要**）
- 建物の種類（戸建て／アパート／店舗）と、おおよその築年数
- 使用した塗料の商品名
- 工期（何日かかったか）

## 掲載してはいけないもの（必ず確認してください）

- **表札・郵便物・車のナンバー** — 写っていたら撮り直すかぼかします
- **窓に映り込んだ室内**
- **隣家がはっきり分かる構図**
- **お客様の建物そのもの** — 掲載の許可を取っていない場合は使えません。
  「ホームページやSNSに載せてもいいですか」と一言もらってください

---

## 写真がない場合はどうなるか

記事は書けますが、文章だけの一般論になり、ポータルサイト（ヌリカエ等）の
記事と差がつきません。**実物の写真は、比較サイトが絶対に持っていない、
辰弥塗装工業だけの武器です。**

写真が用意できるまでは、記事の末尾に「この記事に入れたい写真」を具体的に
書いて納品します。後から差し込めるようにしておきます。
