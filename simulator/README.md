# 株式投資シミュレータ(ペーパートレード)

実在の株価(Yahoo Finance)を使って、**実口座を使わずに**「AIの銘柄選定・売買判断で
利益が出せるか」を検証するためのシミュレータです。実際のお金は一切動きません。

- Python 3.11+ / Streamlit(UI)/ SQLite(永続化)/ yfinance(株価)
- 対象: 東証全上場銘柄(JPX一覧)+ NYSE / NASDAQ 全上場銘柄(nasdaqtrader.com)
- 複数ポートフォリオ(例:「自分の判断」「Claude判断」)を並走して成績を比較

## セットアップ

```bash
cd simulator
python3 -m venv .venv
source .venv/bin/activate        # Windowsは .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。データは `data/sim.db`(SQLite)に保存されます。

## 使い方

1. **ポートフォリオ作成**(サイドバー)
   初期資金は 1万/5万/10万/30万/50万/100万円のプリセットか自由入力(1万〜100万円)。
2. **銘柄マスタ更新**(「🔍 銘柄検索・マスタ」ページ)
   - 🇯🇵 JPX「東証上場銘柄一覧」(data_j.xls)から内国株式を取込
   - 🇺🇸 nasdaqtrader.com の nasdaqlisted.txt / otherlisted.txt から取込
   - プロキシ等でダウンロードできない場合は、同ページの**ファイルアップロード**から取込可能
   - マスタ未取込でも、ティッカー直接入力(例 `7203.T` / `AAPL`)での取引は可能
3. **取引**(「💱 取引」ページ)
   ティッカー・売買・数量・理由メモを入力して発注。発注前に日足チャート(ローソク足)を確認できます。
4. **ダッシュボード**
   総資産・現金・評価損益・税引後実現損益・保有一覧・資産推移と指数比較
   (日経平均 / S&P500 / 全世界株式)。起動時に当日分の総資産スナップショットを自動記録します。
5. **設定**
   手数料率(日本株デフォルト0.1%、米国株0.45%)・為替スプレッド(片道25銭)・
   日本株の単元未満株取引ON/OFF。

## AI売買判断モード

「実際にClaudeに運用させる」ためのワークフローです。

1. 「🤖 AI連携」ページで **「Claudeに判断させる(状況を書き出す)」** を押す
   → `ai_input/YYYYMMDD_HHMM.md` に現在のポートフォリオ・保有・市況・取引ルール・
   出力形式(JSONスキーマ)がまとめて書き出されます。
2. そのファイルをClaude Code等に読ませます。指示例:
   > `ai_input/20260914_0900.md` を読んで、売買指示を `ai_orders/orders.json` に保存して
3. 返ってきたJSON(形式は下記)を「② 売買指示JSONの取込」で選択(またはアップロード)し、
   内容を確認して **一括発注**。取引はタグ「AI」で記録されます。

```json
[
  {"ticker": "7203.T", "side": "buy", "qty": 100, "reason": "自動車セクターの出遅れを拾う"},
  {"ticker": "AAPL", "side": "sell", "qty": 5, "reason": "利益確定"}
]
```

「📈 AI成績」ページで、AIタグ付き取引だけを抽出した
**勝率・平均損益・税引後合計・最大ドローダウン・指数比較**を確認できます。

## 売買ルールの再現

- **現物のみ**(信用・空売りなし)。買いは現金の範囲内、売りは保有数の範囲内
- **単元株**: 日本株100株単位(設定で単元未満=1株単位を許可)、米国株1株単位
- **約定価格**: 取得時点の最新価格(遅延あり、下記参照)
- **手数料**: 約定代金×設定率。取得単価は手数料込みで計算
- **為替**: 米国株は約定時点のUSD/JPY仲値±スプレッド(買い+/売り−)で円換算し、
  適用レートを取引履歴に記録
- **税金**: 「源泉徴収あり特定口座」を近似。売却のたびに、**暦年内の通算実現損益×20.315%**と
  源泉徴収済み額の差分を徴収(利益時)または還付(損失時)します。
  年をまたぐ損失繰越控除・配当は未対応です。

## iPhone・スマホだけで使う(Streamlit Community Cloud)

PCが無くても、無料の Streamlit Community Cloud にデプロイすればスマホのブラウザから使えます。

1. https://share.streamlit.io をスマホのブラウザで開き、**GitHubアカウントでサインイン**
   (リポジトリへのアクセスを許可)
2. **Create app → Deploy a public app from GitHub** で以下を指定して Deploy:
   - Repository: このリポジトリ
   - Branch: 使用中のブランチ
   - Main file path: `simulator/app.py`
   (依存はリポジトリ直下の `requirements.txt` 経由で自動インストールされます)
3. 発行されたURL(`https://〜.streamlit.app`)をホーム画面に追加

**重要な注意(無料クラウドの制約)**:
- サーバーが再起動・再デプロイされると `data/sim.db` が初期化されることがあります。
  **取引をしたら「⚙️ 設定 → バックアップをダウンロード」でiPhoneの「ファイル」に保存**し、
  消えていたら同じ場所から復元してください。
- 一定時間アクセスが無いとアプリがスリープします(開けば数十秒で復帰)。
- アプリのURLを知っている人は誰でも開けるため、公開範囲に注意してください
  (実資金は扱わないので実害は限定的ですが、気になる場合はアプリ設定でアクセス制限を)。

スマホでのAI連携は、①「AI連携」で書き出したMarkdownを**ダウンロード**してClaudeに渡す →
②返ってきたJSONをiPhoneの「ファイル」に保存 → ③「JSONをアップロード」から一括発注、
の流れでファイルパスを使わずに回せます。

## 無料データの制約(重要)

- **yfinance(Yahoo Finance)の価格は15〜20分遅延**です。リアルタイムではありません。
- 個人の調査・学習目的での利用を想定しています(Yahoo Financeの利用条件に従ってください)。
- 過剰アクセス防止のため、現在値は**10分**、日足履歴は**1時間**キャッシュします。
- 休場日・取引時間外は「直近の終値」で約定します(その旨は約定価格からわかります)。
- **eMAXIS Slim 全世界株式は投資信託でyfinanceに無い**ため、同じMSCI ACWIに連動する
  東証ETF **2559.T(MAXIS全世界株式)** を代理として比較します。
- 指数比較は各指数の現地通貨ベース(S&P500の為替変動は未考慮)で、
  「同額を開始日に投資した場合」の形状比較です。
- 米国株ティッカーはyfinance表記に変換して保存します(例: `BRK.B` → `BRK-B`、優先株 `$` → `-P`)。
  ごく一部の特殊な銘柄は取得できないことがあります。

## テスト

ネットワーク不要のユニットテスト(会計・税・単元株・為替換算・マスタ取込・注文JSON検証):

```bash
cd simulator
python -m unittest discover -s tests -v
```

## ディレクトリ構成

```
simulator/
  app.py            Streamlitエントリポイント
  requirements.txt
  sim/              ロジック層(Streamlit非依存・ユニットテスト対象)
    db.py           SQLiteスキーマ・設定
    quotes.py       株価・為替の取得とキャッシュ
    master.py       銘柄マスタ取込(JPX / nasdaqtrader)・検索
    portfolio.py    約定処理(単元株・手数料・税・為替)
    metrics.py      スナップショット・指数比較・AI成績
    ai_bridge.py    AI連携の入出力(ai_input / ai_orders)
  ui/               画面(ダッシュボード/取引/検索・マスタ/AI連携/AI成績/設定)
  tests/            ユニットテスト
  data/             SQLite DB(自動生成・git管理外)
  ai_input/         AIへの状況レポート(自動生成・git管理外)
  ai_orders/        AIからの売買指示JSON置き場(git管理外)
```
