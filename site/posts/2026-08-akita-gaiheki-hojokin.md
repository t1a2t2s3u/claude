「外壁塗装に補助金が使えると聞いたが、本当か」

お見積りの際に、よくいただくご質問です。

結論からお伝えすると、**2026年度（令和8年度）の秋田市では、外壁塗装に
使える可能性のある制度が2つあります。**{.marker}

1. **秋田市住宅リフォーム支援事業** — 一律5万円
2. **秋田県住宅リフォーム推進事業** — 子育て世帯・移住世帯なら工事費の1/2（上限50万円）

ただし、どちらにも条件があります。とくに県の制度は「外壁塗装だけ」では
対象にならないなど、**申し込んでから気づくと手遅れになる注意点**{.marker}が
あるので、順に説明します。

> この記事は2026年8月26日時点の情報です。予算の残りは日々変わり、制度の
> 内容も年度ごとに変わります。実際に使えるかどうかは、必ず各窓口に
> ご確認ください。お見積りの際に一緒に確認することもできます。

## 1. 秋田市住宅リフォーム支援事業 — 一律5万円

秋田市が毎年度行っている制度です。住宅のリフォーム工事に、一律5万円が
補助されます（中心市街地活性化プランで設定した区域内の住宅は10万円）。

**外壁塗装・屋根塗装は、対象工事にはっきり含まれています。** 市が公開して
いる対象工事の具体例に「屋根、外壁、柱、雨樋等の修繕、塗装等の外装工事」と
明記されており、雨樋の交換や屋根の雪止め設置も同じ扱いです。

| 項目 | 内容 |
|---|---|
| 補助額 | 一律5万円（中心市街地の区域内は10万円） |
| 工事費の条件 | 50万円以上 |
| 施工業者 | **秋田市内に本店のある業者**{.marker}が施工すること |
| 対象者 | 市内在住で、市税の滞納がない方（住宅の所有・居住関係にも要件あり） |
| 申請のタイミング | **工事が完成してから**申請 |
| 受付期間 | 令和8年4月1日〜12月28日（工事完了もこの期間内） |
| 回数 | 1つの住宅につき2回まで（同一年度は1回） |
| 窓口 | 秋田市 都市整備部 住宅政策課（☎ 018-888-5770） |

詳細: [秋田市公式サイト「住宅リフォーム支援事業」](https://www.city.akita.lg.jp/kurashi/sumai/1007487/1007790.html)

### 注意 — 先着順で、今年度分は残りわずか

この制度は先着順で、**予算に達した時点で受付が終わります。**{.marker}
市の発表では、令和8年8月25日時点で予算の約97%が埋まっており、残りは
30件弱です。この記事が公開される頃には、終了している可能性があります。

ここ数年は毎年度実施されているので、いま間に合わなくても、**来年度の
春に塗装を予定しているなら、4月の受付開始に合わせて動く**{.marker}のが
現実的です。秋田の塗装シーズンは4月からなので、ちょうど噛み合います
（実施の有無や内容は年度ごとに決まります）。

## 2. 秋田県住宅リフォーム推進事業 — 条件が合えば最大50万円

秋田県の制度です。対象になる世帯が限られている代わりに、金額が大きく
なっています。外壁塗装に関係するのは、次の2つのタイプです。

| 対象世帯 | 補助率・上限 |
|---|---|
| **子育て世帯**（18歳以下のお子さんがいる世帯） | 工事費の1/2、上限50万円 |
| **移住・定住世帯**（県外から移住してきた世帯） | 工事費の1/2、上限50万円（18歳以下のお子さんと一緒の移住は上限100万円） |

このほかに断熱・省エネ改修向けのタイプなどもありますが、そちらは断熱材や
内窓などが対象で、外壁塗装は含まれません。

| 項目 | 内容 |
|---|---|
| 工事費の条件 | 50万円以上 |
| 施工業者 | **秋田県内に本店のある業者**{.marker}と契約すること |
| 申請のタイミング | **原則、工事の着工前**{.marker}に申請 |
| 受付期間 | 令和8年4月1日〜令和9年3月12日（予算がなくなり次第終了） |
| 窓口（秋田市・潟上市の場合） | 秋田地域振興局 建築課（☎ 018-860-3491、受付 9:30〜16:15） |

詳細: [秋田県公式サイト「令和8年度住宅リフォーム推進事業」](https://www.pref.akita.lg.jp/pages/archive/94314)

### 最大の注意点 — 「外壁塗装だけ」は対象になりません

ここがいちばん誤解されやすいところです。県が公開している対象工事の
一覧では、次のように分かれています。

- **屋根の塗装・張替** → 対象
- **外壁の塗装** → **単独では対象外。クラック（ひび割れ）補修や
  サイディングの張替など、外壁の補修を伴う場合に対象**{.marker}

「塗るだけ」の工事は居住環境の向上と見なされず、補修とセットで初めて
対象になる、という考え方です。

実際のところ、秋田の外壁は凍害でひび割れが進みやすく、[塗り替え時期の
記事](/blog/2026-08-akita-nurikae-jiki/)に書いたとおり、**塗装の前に下地の
補修が必要なお宅がほとんどです。** 現地調査で補修箇所を確認し、見積書に
補修工事として明記されていれば、対象になる可能性は十分あります。

逆に言うと、**対象になるかどうかは見積りの内容次第**{.marker}です。
「うちは使えるのか」を確かめてから契約したい方は、着工前申請という
制度の性質上、早めにご相談ください。

## 市と県、両方は使えません

同じ塗装工事に、市の5万円と県の補助を重ねることはできません。秋田市の
制度が、**国・県などの補助対象になった工事（と同じ契約に含まれる工事）を
対象外**{.marker}と定めているためです。

どちらを検討するかの目安は単純です。

- **子育て世帯・移住世帯に当てはまる** → 県の制度（最大50万円）
- **当てはまらない** → 市の制度（5万円）

なお、潟上市など秋田市以外にお住まいの方は、市町村ごとに独自の
リフォーム補助があります。お住まいの市町村の窓口にご確認ください。

## 「補助金で安くなる」を売り文句にする業者にご注意を

補助金の話と切り離せないので、書いておきます。

「補助金を使えば実質タダ」「うちに頼めば必ず補助金が下りる」といった
営業トークには注意してください。ここまで読んでいただいたとおり、

- 補助額は5万円、または条件が合って最大50万円。**工事費全額が出る制度は
  ありません**
- 対象になるかどうかを最終的に判断するのは**市や県の窓口**{.marker}で、
  業者ではありません
- 市の制度は予算に達し次第終了するため、「使えるはず」が使えないことも
  あります

補助金を理由に契約を急がせる話が出たら、いったん持ち帰って、窓口に
直接確かめるのが確実です。

## 申請の手間は、思うほどかかりません

申請書類の多くは、施工業者側が用意するものです。

- 工事の見積書・請負契約書 → **当社が用意します**
- 施工前・施工中・完了後の写真 → **当社が撮影します**（市の申請に必須です）
- 申請書や住民票など → お客様にご用意いただきます

辰弥塗装工業は秋田市の会社なので、**市の「市内業者」・県の「県内業者」、
どちらの要件も満たしています。**{.marker}お見積りの際に「補助金を使いたい」と
お伝えいただければ、使えそうな制度がないか一緒に確認し、必要な書類を
そろえてお渡しします。

現地調査とお見積りは無料です。補助金が使えるか知りたい、という段階の
ご相談でも構いません。
