### 投稿案: 納品物は毎日入れ替える（用途: 育成）
状態: 未投稿

#### X版

```
AI社員の投稿ドラフトを「未投稿のまま翌日になったら失効」というルールにした。毎朝、その日の3本だけが納品される。

ためた在庫は結局読まない。AIは毎日いくらでも書けるのだから、ストックより鮮度。人間側の管理コストを下げる設計が結局いちばん効く。
```

#### Threads版

```
AI社員チームの運用ルールをひとつ変えました。SNS投稿のドラフトは「未投稿のまま翌日になったら失効」。納品ページには常にその日の3本だけが並びます。

変えた理由は単純で、たまった在庫は結局読まれない、です。AI社員は毎日書けるので、投稿を数日休むと未投稿ドラフトが9本たまりました。9本並んだページを見た瞬間、選ぶのが億劫になって手が止まる。これは私の意志力の問題ではなく、設計の問題だと思いました。

古い分は消えても、AIがまた今日のぶんを書いてくれる。過去分も履歴には全部残っている。そう割り切ったら、毎朝「今日の3本」だけに向き合えばよくなって、気が楽になりました。

AIとの分業は、AIの生産力ではなく「人間の消化力」に合わせて設計するのが正解みたいです。
```

#### Threads版

```
AI社員チームの種明かしを少し。うちのAI社員は、1人1枚の「指示書」で動いています。中身は、役割の宣言、定期稼働の手順、そして「してはいけないこと」。人間でいう雇用契約書と職務マニュアルを足したようなものです。

同じAIでも、この指示書ひとつで秘書にも編集長にも校閲にもなります。逆に言えば、AI社員の仕事の質は指示書の質で決まる。私はコードが書けないので、全部日本語の文章で書いています。

いま編集部では、この指示書を実物のまま公開する記事を準備中です。実際に毎日動いているチームの指示書をそのまま見せて、書き方のコツとよくある失敗も添える予定。「AI社員を作ってみたいけど、指示に何を書けばいいかわからない」という人に届けたい内容です。noteで出します。
```
