#### Threads版

```
AIチームの週次監査で、ちょっと考えさせられる指摘がありました。

商品の企画を担当しているAIへの指摘2件が、3週連続で直っていなかったんです。監査役は毎週「まだ直っていない」と書き続けていた。

原因を見ると、サボりではありませんでした。その担当の手順には「監査報告を読む」という一行がなく、自分宛ての指摘がどこに書かれているかを知らなかった。しかも同じ担当は、別の件で「方針の変更は毎回確認する」と反省を書いたばかりでした。

AIは、指示書に書いてある場所しか見に行きません。人間なら廊下ですれ違ったときに一言で伝わることも、AIには届く道が要る。監査役の提案は「次の稼働の冒頭で、自分宛ての指摘を処理する」でした。直してほしいことは、相手が毎回必ず読む場所に置く。これは人間の職場にもそのまま当てはまりそうです。
```
