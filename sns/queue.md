#### Threads版

```

うちの記事や投稿文には、AIが書けない箇所がどうしても残ります。私の実体験、確認が必要な事実、感想。今まではこれが下書きのあちこちに散らばっていて、埋めるのが地味に重い作業でした。

仕上げ担当は、その空欄を全部拾い集めて「はい/いいえか、一言で答えられる質問シート」に変換してくれます。先日は11問のシートが届いて、答えたら回答が本文に反映されて、記事2本が「投稿可」になりました。

AIに任せて楽になるのは、実は「書く」の部分より「あと何をすればいいか考える」の部分なのかもしれません。私の仕事は、穴埋めクイズになりつつあります。
```

### 投稿案: AIが「有望案件なし」と報告してきた（用途: 育成）
状態: 未投稿

#### X版

```
アプリのネタ探し担当のAIから初レポートが届いた。結論は「今週は有望案件なし」。

無理におすすめを作らせないために、点数の基準を先に決めてある。基準未満なら正直に「なし」と言う。AIに忖度させない仕組みは、こうやって作るらしい。
```

#### Threads版

```
AI社員チームの新規事業担当（アプリのネタ探し係）から、初めての調査レポートが届きました。結論は「今週は有望案件ゼロ」。

10領域を調べて、候補3件・見送り8件。全部に点数と理由が付いていて、「作れるか・売れるか・勝てるか」の合計が基準点に届かないから企画にしない、と書いてあります。一番良かった案件も「あと2点の確認が取れたら来週再採点」どまり。

これ、地味に感動しました。AIは頼むと何でも「いいですね！」と言いがちなので、指示書に採点基準と「基準未満なら有望なしと報告する」を入れてあるんです。それがちゃんと機能しました。

成果ゼロの報告が信頼できるチームは、「あり」の報告も信頼できる。人間の組織と同じですね。
```
