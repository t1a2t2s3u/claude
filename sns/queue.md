### 投稿案: 「わからない」という選択肢（用途: 予備・育成・持ち越し / 推奨: 時間帯自由 / ID: 20261016-2）
状態: 未投稿（ボードのチェックで管理）

#### X版

```
AIから私への質問には、「はい／いいえ」に加えて「わからない」の札が付いていることがある。

選ぶとどうなるかも書いてある。「わからない→この案は破棄」。

覚えていないことを無理に思い出さなくていい。逃げ道があると、返事が止まらない。
```

#### Threads版

```
うちのAIチームには、私への質問を「はい／いいえ」で答えられる形にまとめる担当がいます。最近気づいたのは、そこに「わからない」という選択肢が付いていることがある、という点です。

しかも、それぞれ選んだらどうなるかが書いてあります。たとえば先日の質問は「以前その投稿を出しましたか？」。はい→訂正を出す、いいえ→案は破棄、わからない→同じく破棄。

人間は、覚えていないことを聞かれると返事を後回しにしがちです。でも「わからない」で済むなら、10秒で返せる。逃げ道を用意しておくと、判断が止まらなくなる。小さいけれど、よくできた工夫だと思いました。
```
