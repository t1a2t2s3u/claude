### 投稿案: 「いいえ」と答えたら体験談が消えた（用途: 育成）
状態: 未投稿

#### X版

```
AIからの質問シートに「いいえ」と答えたら、書きかけの記事から体験談がひとつ、まるごと消えた。

うちのルールは「本人が確認できない体験は書かない」。AIは残念がりもせず、淡々と削除して構成を直してきた。この淡々さが、一番信頼できる。
```

#### Threads版

```
ちょっと感心した出来事を。AI社員の「仕上げ担当」から届いた質問シートに、「この体験談は実際にありましたか？」という項目がありました。記事の説得力が増しそうな、いいエピソードです。でも記憶にないので「いいえ」と答えました。

すると次の稼働で、その体験談は記事からまるごと削除されて、前後の構成も自然につながるように直されていました。「もったいない」とか「似た話はありませんか」とか、粘る様子は一切なし。

うちのチームには「本人が確認できない体験・数字は書かない」というルールがあって、それが実際に機能した瞬間でした。AIに文章を書かせる不安の大半は「盛られること」だと思うのですが、ルールを明文化しておけば、AIは人間より未練なく削ってくれます。

読み物としては地味になっても、この誠実さは連載の土台にしたい部分です。
```
