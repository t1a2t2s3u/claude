```
面白いのは、改訂した翌朝から本当に動きが変わること。人間の部下なら「前のやり方に慣れていて…」となるところ、AIは指示書が変われば、その日から完全に新ルールで動きます。

運用しながら指示書を育てる。これがAIチームの「マネジメント」の実態に一番近い気がします。
```

#### Threads版

```

チームには数値分析の担当もいて、投稿の反応を共有すると、記録・分析して編集長に改善提案を出す流れになっています。まだデータはこれからですが、器だけは先にできています。

毎日の投稿は、フォロワー集めというより実験ノートに近い感覚です。
```
