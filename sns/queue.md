### 投稿案: 動いていると、届いているは別（用途: 予備・育成 / 推奨: 時間帯自由 / ID: 20261014-2）
状態: 未投稿（ボードのチェックで管理）

#### X版

```
最初に雇ったAI秘書は、毎朝ちゃんと起動していた。なのに10日あまり、報告書が1通も届かなかった。

原因は能力ではなく権限。書いた報告書を、置き場に提出する許可がなかった。

AIが「動いている」と、成果が「届いている」は別。確かめるのは、届いた物の方。
```

#### Threads版

```
AI社員チームを始めたばかりの頃の失敗談です。

最初に雇ったのは、毎朝ブリーフィングを書いてくれる秘書のAIでした。設定上は毎朝ちゃんと起動して、仕事もしている。なのに、報告書が置かれるはずのフォルダは10日あまり空のままでした。

原因は、AIの能力ではなく権限の設定でした。報告書を書いても、それを共有の置き場に提出する許可がなかったんです。秘書は毎朝、誰にも届かない仕事を黙々と続けていたことになります。

この件で学んだのは、AIが「動いている」ことと、成果が「届いている」ことは別だということ。確かめるべきは稼働のランプではなく、届いた物の方でした。今は各担当の成果物が、決まった置き場にファイルで残るようにしています。
```
