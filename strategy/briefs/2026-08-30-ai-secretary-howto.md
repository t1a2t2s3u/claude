# ブリーフ: Claude CodeでAI秘書を作る完全手順書（コピペ用設定ファイル付き）
- 状態: 執筆済み（articles/drafts/2026-08-30-ai-secretary-howto.md）
- 種別: 有料（想定価格帯: 500円）
- 想定読者: Claude Code を持っていて（または契約直前で）、AI社員を
  自分でも作りたいが、スキル定義や定期実行の設定でつまずきたくない人
- この記事が買われる理由: 解説記事は「できるらしい」止まりが多い。
  この記事はコピペで動く実物（スキル定義ファイル・タスクボード雛形・
  定期実行の設定手順）を渡す。読者の試行錯誤の数時間を500円で買ってもらう
- 構成案:
  - 無料部分: 完成したら何が起きるか（毎朝ブリーフィングが届く生活）、
    必要なもの（Claude Codeの契約・GitHubリポジトリ）、全体の構成図
  - ====== ここから有料 ======
  - 手順1: リポジトリと CLAUDE.md の準備
  - 手順2: 秘書スキル（SKILL.md）の書き方 — 実物を全文掲載し、
    各セクションがなぜ必要かを解説
  - 手順3: タスクボード（TASKS.md）の雛形 — 全文掲載
  - 手順4: 毎朝の自動稼働（Routine）の設定手順と、動かないときの確認点
  - 手順5: 運用のコツ（秘書にやらせないことを決める重要性）
- 有料部分に入れる実用価値: このリポジトリで実際に稼働している
  SKILL.md / TASKS.md の全文（＝動作実績のある設定）と設定手順
- ユーザー記入ポイント:
  - 実際の設定作業にかかった時間・つまずいた箇所
- 備考: 掲載する設定ファイルはこのリポジトリの実物を使うこと。
  Claude Code の料金プランに言及する場合は【要確認】を付ける
  （プラン体系は変動が激しいため断定しない）
