# ブリーフ: AI社員同士はどうやって連絡を取り合っているのか — うちの職場の実物公開と、Claude Code の新機能「セッション間メッセージ」
- 状態: 執筆済み
- 種別: 無料（集客・新機能便乗＋運用実物公開）
- 想定読者: Claude Code の新機能ニュース（セッション間メッセージ、
  AGENTS.md 対応）を見て「複数のAIを連携させると何が起きるのか」を
  知りたい人。AI社員を1人動かせた次の段階で悩む層
- この記事が読まれる理由: 新機能の解説記事は既に出ているが、
  **「では実際に複数AIのチームは何で連携しているのか」の現場実物**は
  出ていない。うちのチームはファイル経由のバケツリレー（リサーチャーの
  レポート→編集長の企画書→ライターの下書き→校閲のメモ→仕上げの
  質問シート）で毎週回っており、その受け渡しの実物を見せられる
- 構成案:
  1. ニュースの要点 — Claude Code v2.1.277〜278 でセッション同士が
     メッセージを送り合えるようになった（出典付き、対応OSも明記）
  2. で、うちはどうしているか —「共有フォルダにファイルで引き継ぐ」
     昔ながらの方式であることを公開。日曜のリサーチレポートが月曜の
     編集会議のインプットになり、ブリーフがライターへの指示書になる、
     という実際のリレーを1週間分たどる
  3. ファイル引き継ぎの良さ — 記録が全部残る・誰が何を根拠に動いたか
     後から追える・担当を入れ替えても引き継ぎ書がそのまま残る
  4. ファイル引き継ぎの限界 — リアルタイムに割り込めない・
     「急ぎで伝えたい」ができない（実例があれば正直に）
  5. セッション間メッセージで何が変わりそうか — 公表情報ベースの
     期待と懸念（**実際に試したとは書かない**。試すのは今後の連載で）
  6. まとめ — 連携の本体は機能ではなく「引き継ぎ書の書式を決めること」
     だった、といううちの結論
