# ブリーフ: AIが承認ボタンを押さなくなる日 — 自動モード既定化と、それでも人間が押す「第3層」の話
- 状態: 執筆済み
- 種別: 無料（集客・ニュース読み解き。有料「何をどこまで任せるか」への導線）
- 想定読者: Claude の自動モード既定化のニュースを見て「承認なしで
  動くようになるのは便利なのか怖いのか」を判断しかねている人。
  AI社員・エージェント運用者全般
- この記事が読まれる理由: 「自動モードが既定になる」という変化を、
  機能解説でなく**「任せる範囲を2ヶ月自分で線引きして運用してきた
  当事者」の視点**で読み解く。承認が分類器（AIの判定役）に移っても
  「人間が押すべきボタン」は残る、という実運用からの答えを出せる
- 構成案:
  1. ニュース: 自動モードが新規セッションの既定になる —
     操作ごとの人間の承認の代わりに、分類器が実行可否を判定する仕組み
     （公式ページ＋報道。**時期は「10月下旬時点で既定化が案内されている」
     の粒度で書き、日付を断定しない** — 公式ページ内で時期の記述が
     食い違っているため。執筆時に公式ページを再確認し確認日を明記）
  2. 何が変わるのか — 「全部自動になる」ではなく「承認の担当が
     人間→分類器に変わる」が正確な理解、という整理。Duet の
     「外に出る行動の前は承認」も同じ分類器を通ると報じられている点
     （出典付き）
  3. うちの三層ルールと突き合わせる — ①勝手にやってよい
     ②やってから報告 ③人間の承認が必要（公開・支払い・方針変更）。
     自動モード既定化後も、第3層を人間に残す理由を実体験から
     （止まっていたのは人間だった問題も正直に: 第3層は安全装置で
     あると同時に詰まりどころでもある、という両面）
  4. 実際に設定し直してみた — `/auto-mode-setup`（環境に合わせて
     自動モードを設定するガイド機能）をうちのリポジトリで実行し、
     何が提案されたかを記録（**機能の存在・挙動は公式変更履歴で
     要確認。実行できない場合はこの節を「うちならこう設定する、を
     三層ルールから机上で整理した」に差し替え、実行したとは書かない**）
  5. まとめ — 既定値は変わっても「何を人間に残すか」を自分で決めた
     経験は無駄にならない。詳しい線引き表は有料記事へ（誘導）
