# ブリーフ: AIに財布を預けられるか — 「購入のたびに人間が承認」が世界標準になった週に、うちの第3層ルールを答え合わせする
- 状態: 未着手
- 種別: 無料（集客・ニュース読み解き。有料「何をどこまで任せるか」への導線）
- 想定読者: 「AIが買い物まで代行する」ニュースを見て、便利さと不安の
  両方を感じた人。AIエージェントに支払い・契約系の仕事を任せるか
  迷っている運用者・一般読者
- この記事が読まれる理由: ChatGPT Wallet の紹介記事は出揃うが、
  **「お金が動く仕事は人間が押す」というルールを2ヶ月半前から自分の
  チームに課して運用してきた当事者が、各社の製品設計と答え合わせする**
  視点は他にない。「自分はどこに線を引くべきか」まで持ち帰れる
- 構成案:
  1. ニュース: ChatGPT Wallet（11/13・米国Pro向け）— AIエージェントが
     購入を代行するが、**購入ごとに品物・金額・カードを人間が確認し
     生体認証で承認**。カード番号は渡さず取引ごとの決済トークンのみ
     （出典付き。**米国限定のため「使ってみた」は絶対に書かない**）
  2. 各社の線を並べる — Claude Duet は銀行振込を完全ブロック、
     Claude Code は自動モードでも外に出る行動は確認、という
     「お金と承認」の既定値の揃い方（一次確認済みの範囲のみ）
  3. うちの答え合わせ — 2ヶ月半前に素人が決めた第3層
     「お金が動く・外に出る・ルールを変える仕事は人間の承認」が、
     各社の製品設計と同じ線だったこと。自慢でなく「怖がりの素人の
     直感は案外正しかった」のトーンで
  4. ただし線は動く — OpenAI は「事前承認に基づく自律決済」を計画
     （出典付き）。「今の線」を暗記するのではなく「線が動いたときに
     何を人間に残すか」を自分で決め直せることが本体、という結論
  5. 読者向けミニ指針 — AIにお金を任せる前の3つの質問
     （上限はあるか・取り消せるか・記録が残るか）。一般論の範囲で、
     金融アドバイスはしない
  6. 関連誘導（承認疲れ記事・有料「何をどこまで任せるか」）
