# ブリーフ: ニュースで Claude を知ったあなたへ — プログラミング未経験の私は、この3ヶ月AI社員と暮らしてきた
- 状態: 執筆済み
- 種別: 無料（集客・最重要の入口記事。上場ニュースで Claude を知った
  完全な新規層向け）
- 想定読者: Anthropic 上場のニュースで「Claude」という名前を初めて
  知った人。「AIで生活が変わるって本当？」レベルの、連載中で最も
  手前にいる読者。AI社員・エージェントという言葉も知らない前提で書く
- この記事が読まれる理由: 上場を機に「Claude とは」解説記事と
  投資・株記事が急増するが、**「3ヶ月実際に使って生活がどう変わったかを、
  プログラミング未経験の個人が具体的に語る」記事**はほぼない。
  検索・AI検索で「Claude とは 何ができる」を調べた人の
  「結局、普通の人の役に立つの?」という本音に正面から答える
- 構成案:
  1. つかみ — ニュースで名前を見たあの会社のAIを、コードが書けない
     自分は3ヶ月毎日使ってきた、という自己紹介（上場の事実に1文だけ
     触れる。**株価・投資・買い方の話は一切しない**。数字は
     「上場した」以上に書かない）
  2. 何をしているか — 毎朝ブリーフィングが届く、週に1回編集会議が
     開かれる、記事の下書きが勝手に増えていく、という日常を
     具体的な1週間で見せる（専門用語ゼロを目標に。「AI社員」も
     初出時に言い換えで説明）
  3. 全部日本語で頼んだだけ — 設定もコードも書いていない、
     チャットで日本語の指示書を書いてもらった、という事実
     （承認済みペルソナの範囲）
  4. 正直な現実 — 魔法ではない: AIはよく働いたが、公開ボタンを
     押せない人間（自分）が詰まりどころだったこと、AIは間違えるので
     疑う係を置いていること（連載へのリンクで深掘りに誘導）
  5. 始めてみたい人へ — 大それた自動化でなく「毎朝のメモ書き係を
     1人雇う」から始めるのが現実的、という提案（有料手順書への
     導線は1行まで。入口記事を広告にしない）
  6. 連載の目次 — 運用日記第1回〜と主要記事への案内で締める
