## 今週のネタ候補（優先順に5件前後）

1. **候補: 「noteはAI利用の明記が義務になった」は本当か — 公式を確認してみた** —
   なぜ今か: 「2026年の新規約でAI利用の明記が必須・完全自動生成は禁止」と
   書くnote記事・ブログが複数出回っている。一方でnote公式のヘルプで
   確認できるのは「AIアシスタントの利用条件」「AI学習の拒否設定」
   「AI学習対価還元プログラム」で、**表記義務を定めた公式文書は
   今回の調査では見つからなかった**【未確認】。逆に「ガイドラインに
   AI利用のことは書かれていない」と指摘する記事もある。噂が広がって
   いる今、AIで下書きを作っていると開示しているうちが一次資料を
   確かめて書くと、信頼の実例になる。既存ブリーフ「AI開示で何が違うか」の
   補強材料にもなる。
   想定の切り口: 噂の出どころと公式文書を並べて、何が確認できて何が
   できないかを書く（断定は公式文書を確認してから）。
   参考: https://note.com/robokuma1234/n/n15f996eb9c56 /
   https://note.com/jazzy_hawk1655/n/ne8adbf47d6f9 /
   https://note.com/_record/n/n0d1ebf04355f /
   https://www.help-note.com/hc/ja/articles/44723422427417
2. **候補: 見張り役のAIを雇う — Claude Code の新しい内蔵mod「You should know」** —
   なぜ今か: 10/1 の更新で、作業を横で見ていて見落としを指摘する
   「サイドエージェント」が組み込みmodとして入った。うちは人間ではなく
   監査役AIに「疑う係」をやらせており（運用日記03）、その考え方が
   公式機能になった形。プラグインが挙動をより深く変えられる
   「Claude Mods」も同時追加。
   想定の切り口: うちの監査役（週1回のファイル点検）と、作業中に
   隣で見張る公式機能の違いを、実際に有効化して比べる
   （利用条件: テレメトリONのファーストパーティセッション限定とされる
   ため、うちの環境で使えるかは要確認）。
   参考: https://code.claude.com/docs/ja/whats-new /
   https://code.claude.com/docs/en/changelog
3. **候補: Claude Sonnet 5.5 で「AI社員の人件費」がまた下がった（コスト記事の追加材料）** —

   ※新規企画ではなく、編集長判断済みの「10月下旬コスト記事」への

   参考: https://techcrunch.com/2026/09/28/anthropic-releases-sonnet-5-5-which-it-calls-a-significantly-cheaper-faster-work-partner/ /
   https://siliconangle.com/2026/09/28/anthropic-debuts-claude-sonnet-5-5-running-30-faster-than-the-previous-generation-ai-model/
4. **候補: 「AIに勝手に動かれない」仕組みが標準になってきた** —
   なぜ今か: Anthropic の Managed Agents に、ツール呼び出しごとに
   「実行／拒否／人間の承認待ち」をサーバー側で判定する自動権限ポリシーが

## noteの動向

- **「noteはAI利用の明記が義務」説が拡散中、ただし公式文書は未確認** —
  「冒頭か末尾に『この記事はAIを活用して作成されています』と書く必要が
  ある」「100%自動生成はNG」と断言するnote記事・ブログが複数ある。
  一方、note公式ヘルプで確認できたのは AIアシスタント利用条件・
  AI学習の拒否設定・AI学習対価還元プログラム（2025年8月の規約改定で
  開始、投稿テキストが第三者の学習データ提供の対象に）まで。
  表記を義務づける公式の条文は見つからず【未確認】、「ガイドラインに
  AI利用のことは書かれていない」とする記事もある。
  → 編集部への申し送り: うちは元々AI利用を開示する方針なので実害は
  小さいが、**義務かどうか**を記事で断定する前に、note利用規約・
  ガイドラインの原文確認が必要。
  出典: https://note.com/robokuma1234/n/n15f996eb9c56 /
  https://note.com/_record/n/n0d1ebf04355f /
  https://www.help-note.com/hc/ja/articles/44723422427417 /
  https://note.com/info/n/n21b09699c67d
- **AI学習対価還元プログラムの参加設定** — 投稿記事をAI学習に提供するか
  どうかはクリエイターが設定で選べる。初投稿前にオーナーが設定を
  確認しておく価値あり（判断はオーナー）。
  出典: https://www.help-note.com/hc/ja/articles/47621851095449
- **AI量産の有料記事が売りにくくなっている兆し** — 「有料記事化を
  諦めた」当事者記事、「最後の人間の仕上げで売れるかが決まる」とする
  分析が出ている。先週の「読者の警戒」と同じ方向で、AI下書き＋人間の
  仕上げ＋監査を開示するうちの路線に追い風。
  出典: https://note.com/murata_ssj/n/nf10ad6448f9e /
  https://atsoho.com/blog/note-ai-efficiency-sell
