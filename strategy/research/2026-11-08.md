## 今週のネタ候補（優先順に5件前後）

1. **候補: 「承認疲れ」— 全部確認すると形だけになり、全部任せると事故る** —
   なぜ今か: 自動モード既定化（先週報告）を受けて、「承認」をどう設計
   するかの記事が増えている。「全社導入では承認操作が形骸化し重大事故に
   つながる（承認疲れ）」「全部自動承認で放置は典型的な失敗」「確認を
   切って破壊的コマンドだけ機械的に止める」など、論点が「承認の要不要」
   から「承認の数をどう減らし、どこだけ残すか」に移っている。
   うちは13人分の「してはいけないこと」と三層ルールで、人間が押す箇所を
   最初から絞っている。その実物と、実際にオーナーが何回承認したかが
   一次情報になる。
   想定の切り口: 有料「何をどこまで任せるか」への導線になる無料記事、
   または補足段落の材料（判断は編集長）。
   参考: https://note.com/hirotsuchida/n/n6eee4f612217 /
   https://uravation.com/media/claude-code-hyoban-review-2026/ /
   https://note.com/s_kashiwakura/n/n5354cd45e1d6
2. **候補: 有料記事2本の「無料の競合」が出た — 見せ方の再確認（材料提供）** —
   なぜ今か: 今週、次の無料記事が note に出た。
   - 「Claude Duet は日本で使える？ Claude Code で朝のレポートを再現する」
     （Claude Code研究所）— うちの有料「AI秘書の完全手順書」とほぼ同じ
     ゴール（毎朝レポートが届く秘書）
   - 「Claude Duet はまだ日本で使えない — でも、AIに任せる前に知るべき
     『承認の3段階』」（kota）— うちの有料「何をどこまで任せるか」の柱
     （三層設計）と同じ枠組み
   中身（有料部分があれば）は見ていない。見出しと冒頭からの傾向だけで、
   **「手順」と「三層の考え方」はもう無料で手に入る**状態になりつつある。
   うちの有料記事に残る価値は、**13人分の実ファイル全文**と、
   **実際に起きた事故と直し方の記録**。
   ※新規企画ではない。有料記事の無料部分（購入理由）の見直し要否の
   判断材料として編集長・オーナーに提示（価格の決定はオーナー）。
   参考: https://note.com/claudecode_lab/n/n5684ab1cb556 /
   https://note.com/apt_python9821/n/n682e65c50e99
3. **候補: 送信前に「メールアドレスを外に出していいか」を聞くようになった — v2.1.317** —
   なぜ今か: 公式変更履歴によると、v2.1.317（11/2）で、Web やシェルの
   ツール呼び出しがアカウントのメールアドレスをネットワークに送る前に
   確認するプライバシーチェックが入った。うちの AI社員も外部サイトを
   調べて回っており、「AIが勝手に個人情報を外に出さないか」は
   非エンジニア読者の素朴な不安に直結する。
   想定の切り口: 小ネタ（運用日記の一節・SNS向き）。実際にうちのセッションで
   この確認が出たかを記録できれば一次情報になる。
   参考: https://code.claude.com/docs/en/changelog
4. **候補: `.claude/skills` に置いたプラグインが自動で読み込まれるように** —
   なぜ今か: 公式変更履歴によると、`.claude/skills` ディレクトリ内の
   プラグインがマーケットプレイスなしで自動ロードされるようになった。
   うちの AI社員13人はまさに `.claude/skills/` に1人1ディレクトリで
   住んでいる。有料「雇用契約書（スキル定義ファイル）の書き方」の
   手順の前提が変わるか、執筆側で確認する価値がある。
   想定の切り口: 優先度は中。有料記事の手順に影響があるかの確認が先
   （影響がなければ記事化は不要）。
   参考: https://code.claude.com/docs/en/changelog
5. **候補: 「AIが書いたことを証明する」技術 — Anthropic FlashProve** —
   なぜ今か: Anthropic が、AIの回答がどのモデルから出たかを暗号技術で
   証明する研究用プロトタイプ「FlashProve」をオープンソースで公開した
   （11/2〜3）。ただし**製品ではなく、Claude でも動かず、導入予定も
   ない**研究段階。AI開示スタンスの記事（9/28 ブリーフ化済み）の
   背景として「AIが書いたかどうかを技術で示す研究も進んでいる」と
   1文添える程度。
   参考: https://techcrunch.com/2026/11/03/anthropic-is-working-on-a-system-to-prove-ai-models-identity/ /
   https://thenextweb.com/news/anthropic-flashprove-provable-inference-ai-model-identity

- **有料の中身が無料化していく速度が上がった** — Duet 発表から3週間で、
  「秘書を手作りする」「承認を3段階で考える」という、うちが有料記事に

  (c) 監査・仕上げを含む工程の実物。
  → 編集部への申し送り: 有料3本の無料部分で、この3点が購入理由として
  前に出ているかの再点検を推奨（判断は編集長、価格はオーナー）。
  出典: https://note.com/claudecode_lab/n/n5684ab1cb556 /
  https://note.com/apt_python9821/n/n682e65c50e99
