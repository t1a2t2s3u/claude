1. **候補: AIが代わりにお金を払う時代 — 「お金が動く仕事は人間が押す」の答え合わせ** —
   なぜ今か: 11/13、OpenAI が「ChatGPT Wallet」を米国の Pro 加入者向けに
   開始した。エージェント「dots」が商品を探して購入まで代行するが、
   **購入ごとに品物・合計金額・使うカードを確認し、生体認証で承認**する。

   各社の製品設計がそろってきた。OpenAI は将来の「事前承認に基づく

   想定の切り口: 有料「何をどこまで任せるか」・承認疲れ記事の補強素材、

## Claude Code / AI社員界隈（連載の差別化に影響する動き）

- **「お金」と「承認」の設計が各社でそろってきた** — ChatGPT Wallet
  （購入ごとに生体認証）、Claude Duet（振込はブロック）、Claude Code の
  自動モード既定化と、各社とも「お金が動く・外に出る行動は人間の承認」を
  既定にしている。うちが2ヶ月前に手作りで決めた第3層と同じ線。
  一方で OpenAI は事前承認による自律決済も計画しており、
  **この線は今後も動く**。有料「何をどこまで任せるか」は、
  「今の線」と「動き続ける線への備え方」の両方を書けると古くなりにくい
  （判断は編集長）。
  出典: https://techcrunch.com/2026/11/13/chatgpts-new-wallet-lets-ai-agents-shop-and-check-out-for-you/ /
  https://claude.com/resources/articles/claude-duet
- **Claude が一般ニュースになった** — 上場で「Claude」という名前を
  初めて聞いた層が増える。連載第1回（秘書を雇った話）と入口記事の
  想定読者が一段広がった週。
